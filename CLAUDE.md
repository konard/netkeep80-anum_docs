# CLAUDE.md — Руководство для AI-ассистентов

Этот файл содержит инструкции для AI-ассистентов (Claude Code, GitHub Copilot и др.), работающих с проектом протокола ачисел МТС.

## Обзор проекта

Это репозиторий документации и инструментов для **Метатеории Связей (МТС)** — фундаментальной формальной системы, основанной на единственном примитивном понятии направленной связи.

**Ключевые компоненты:**
- **core/** — Ядро системы (аксиомы, система нотации)
- **parsers/** — Парсеры ачисел и формул MTC
- **converters/** — Конвертеры между форматами нотаций
- **docs/theory/** — Теоретические основы МТС
- **tests/** — Тесты

## Критические правила

### Запрещённые действия

1. **НЕ создавай файлы в корне проекта** — все файлы в соответствующие подкаталоги
2. **НЕ используй старую нотацию абитов** (♂, ♀, →, ,) — только: `(`, `)`, `+`, `-`
3. **НЕ трактуй ∞ как абит** — это мета-конструкт, выражаемый как `() ≡ ∞`
4. **НЕ создавай дублирующие реализации** без консультации

### Обязательные действия

1. **Спрашивай перед созданием файлов** — запроси разрешение и местоположение
2. **Используй существующую структуру** — соблюдай установленную структуру каталогов
3. **Следуй нотации** — используй только корректную четверичную систему абитов
4. **Сохраняй архитектуру** — поддерживай разделение практического и теоретического уровней
5. **Предпочитай обновление** — обновляй существующие файлы вместо создания новых
6. **Валидируй изменения** — запускай тесты после модификаций

## Нотация МТС

### Абиты (практический уровень) — 4 символа

| Символ | Значение | Формула |
|--------|----------|---------|
| `(` | Начало связи | ♂∞ → ∞ |
| `)` | Конец связи | ∞ → ∞♀ |
| `+` | Наличие связи | ♂∞ → ∞♀ |
| `-` | Отсутствие связи | ∞♀ → ♂∞ |

### Формы связей (мета-уровень) — НЕ абиты

| Символ | Значение |
|--------|----------|
| `∞` | Полностью самозамкнутая связь (выражается как `()`) |
| `♂` | Связь с самозамкнутым началом |
| `♀` | Связь с самозамкнутым концом |
| `→` | Связь без самозамыканий |

### ASCII совместимость

```
(   ≡ (     (абит)
)   ≡ )     (абит)
+   ≡ +     (абит)
-   ≡ -     (абит)
()  ≡ ∞     (акорень — комбинация абитов)
M   ≡ ♂     (форма связи)
F   ≡ ♀     (форма связи)
->  ≡ →     (форма связи)
```

## Выполнение Python

**Важно:** На Windows используй `py` вместо `python`:

```bash
# Правильно
py script.py
py -m pytest tests/

# Неправильно
python script.py
python3 script.py
```
