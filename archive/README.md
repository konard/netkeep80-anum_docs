# Архив

Файлы в этом каталоге являются историческими черновиками и промежуточными версиями МТС.

После issue #42 архивные тексты нельзя использовать как актуальную спецификацию без явной проверки. Особенно осторожно нужно читать места, где:

- `{}` трактуется как пустое множество или готовое множество связей;
- `[]` используются как формульные скобки или экранирование;
- старая система А0–А16 подаётся как финальная;
- формальная нотация, ачисла и асеть смешиваются на одном уровне.

Актуальная рамка начинается с [Оснований МТС](../docs/theory/Основания%20МТС.md).

Сюда также перенесён исторический анализ скобок, потому что он содержит старые гипотезы о `{...}` и `[⟼]`, которые не должны лежать рядом с актуальной теорией.
