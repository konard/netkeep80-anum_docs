# Проработка аксиом начальности и конечности (самозамыканий начала и конца)

Статус: исторический.

Документ перенесён из активного research-раздела после issue #42. Он сохраняется только как черновой контекст и не задаёт актуальную систему аксиом.

> **Примечание:** Данный документ описывает анализ старой системы аксиом (А0-А11). После issue #42 актуальная система аксиом ведётся отдельно: [`Система аксиом МТС`](../docs/theory/Система%20аксиом%20МТС.md).

## Постановка задачи

В МТС имеются четыре формулы, связанные с самозамыканием:

| № | Формула | Имя | Статус |
|---|---------|-----|--------|
| 1 | `♂v : ♂v ⟼ v` | Конечность — самозамыкание начала (А5) | Аксиома — вводит оператор `♂` |
| 2 | `r♀ : r ⟼ r♀` | Начальность — самозамыкание конца (А6) | Аксиома — вводит оператор `♀` |
| 3 | `♂∞ = ♂∞ ⟼ ∞` | Конец смысла | Следствие А5 при `v = ∞` |
| 4 | `∞♀ = ∞ ⟼ ∞♀` | Начало смысла | Следствие А6 при `r = ∞` |

Задача: разобраться с их соотношением, выяснить что они вводят, и уточнить формальный статус каждой.

## Анализ

### Аксиомы (А5, А6) вводят новые символы

Аксиомы А5 и А6 — это **определения** (используют `:`), потому что они вводят **новые операторы**:

- **А5 (Конечность)** вводит символ `♂` (префиксный унарный оператор самозамыкания начала) — если нет начала, то остаётся только конец
- **А6 (Начальность)** вводит символ `♀` (постфиксный унарный оператор самозамыкания конца) — если нет конца, то остаётся только начало

До А5 и А6 в системе нет операторов `♂` и `♀`. Именно эти аксиомы определяют их через `:`.

### Начало и конец смысла — следствия, а не аксиомы

Формулы `♂∞ = ♂∞ ⟼ ∞` и `∞♀ = ∞ ⟼ ∞♀` **не вводят новых символов**. Все символы в них (`♂`, `♀`, `∞`, `⟼`) уже определены аксиомами А3–А6. Поэтому:

- `♂∞ = ♂∞ ⟼ ∞` — это **частный случай** А5 при подстановке `v = ∞`
- `∞♀ = ∞ ⟼ ∞♀` — это **частный случай** А6 при подстановке `r = ∞`

Здесь должен использоваться знак **равенства** `=`, а не **определения** `:`, потому что это не акт введения нового знака, а следствие применения уже существующих аксиом.

### Фундаментальность: что первично?

Автор issue отмечает парадокс: аксиомы начала и конца смысла «по идее более фундаментальные, потому что рождаются из акорня первыми». Это связано с **логической иерархией порождения**:

1. **А4 (Смысл)** порождает `∞` — онтологический якорь
2. **А5, А6 (Самозамыкания)** порождают операторы `♂` и `♀`
3. Применение `♂` и `♀` к `∞` немедленно порождает `♂∞` и `∞♀`

Таким образом, `♂∞` и `∞♀` — **первые конкретные связи**, которые строятся после определения операторов. Они более фундаментальны *онтологически* (как первые конструкции), но *логически* являются частными случаями более общих аксиом А5 и А6.

### Четыре понятия, вводимые самозамыканиями

Самозамыкания начала и конца вводят четыре фундаментальных понятия:

| Понятие | Формула | Смысл |
|---------|---------|-------|
| **Конечность (самозамыкание начала)** | `♂v : ♂v ⟼ v` | Если нет начала, то остаётся только конец (связь без внешнего начала) |
| **Начальность (самозамыкание конца)** | `r♀ : r ⟼ r♀` | Если нет конца, то остаётся только начало (связь без внешнего конца) |
| **Конец смысла** | `♂∞ = ♂∞ ⟼ ∞` | Конкретная безначальная связь, направленная к акорню |
| **Начало смысла** | `∞♀ = ∞ ⟼ ∞♀` | Конкретная бесконечная связь, исходящая из акорня |

- **Конечность** (♂) — оператор самозамыкания начала: если нет начала, остаётся только конец (извлечение конца связи)
- **Начальность** (♀) — оператор самозамыкания конца: если нет конца, остаётся только начало (извлечение начала связи)
- **Конец смысла** (♂∞) — конкретный экземпляр безначальной связи относительно акорня, занимающий позицию конца в единице смысла
- **Начало смысла** (∞♀) — конкретный экземпляр бесконечной связи относительно акорня, занимающий позицию начала в единице смысла

### Связь с абитами

В А10 записи `[ : ∞♀` и `] : ♂∞` **правомерно** используют `:`, потому что:

- `[` — это **новый символ** (абит), который до А10 не определён
- `]` — это **новый символ** (абит), который до А10 не определён

Аксиома А10 вводит знаки сериализации `[` и `]` через определение `:`.

### Вывод: `:` vs `=`

| Формула | Оператор | Вводит новый символ? | Статус |
|---------|----------|---------------------|--------|
| `♂v : ♂v ⟼ v` | `:` | Да (`♂`) | Аксиома конечности (определение) |
| `r♀ : r ⟼ r♀` | `:` | Да (`♀`) | Аксиома начальности (определение) |
| `♂∞ = ♂∞ ⟼ ∞` | `=` | Нет | Следствие А5 |
| `∞♀ = ∞ ⟼ ∞♀` | `=` | Нет | Следствие А6 |
| `[ : ∞♀` | `:` | Да (`[`) | Аксиома (определение) |
| `] : ♂∞` | `:` | Да (`]`) | Аксиома (определение) |

## Рекомендации для чистовика

1. **А5 и А6** — переименовать в «Конечность» и «Начальность», сохранив как аксиомы-определения с `:`, с явным указанием что если нет начала — остаётся только конец (А5), а если нет конца — остаётся только начало (А6)
2. **Начало и конец смысла** — выделить как **теоремы/следствия** из А5+А4 и А6+А4, используя `=` вместо `:`
3. **А10** — оставить без изменений (корректно использует `:` для введения новых знаков)
4. В описании А5 и А6 добавить раздел о порождении начала и конца смысла как первых конкретных следствий
