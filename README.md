# Метатеория связей (МТС)

## Что сейчас является МТС

МТС строится из постулата:

```text
всё есть связь
```

Формальная нотация МТС — система смысловых различий. Строка формальной нотации МТС есть строковое ачисло, содержащее запись формулы. Формула есть последовательность различий, прочитанная как шаблон формы связи. Результат интерпретации формулы есть связь или асеть связей.

```text
строковое ачисло
→ последовательность различий
→ формула
→ интерпретация формулы
→ связь / асеть связей
```

Каждая аксиома имеет формулу. Система формул аксиом решается одновременно. Корневая система формул является корневой библиотекой апрувера.

## Первичные скобочные нотации

```text
(...) — явная формальная форма / группировка формы
[...] — нотация ачисла; форма одной связи
{...} — пучковая нотация; форма пучка / асети связей
```

Скобки задают границы контейнера нотации. Контейнер задаёт область чтения, а нотация задаёт способ интерпретации различий внутри этой области.

Ключевой блок корневой системы:

```text
∞ : [] = [] ⟼ []
[] = ∞
∞ = ∞ ⟼ ∞
```

`[]` здесь читается как пустая форма одной связи, а не как внешняя переменная. `{}` читается как пустой пучок связей, а не как поиск или ссылка. Круглые скобки явно фиксируют границу уже собранной формальной формы.

## Где система аксиом

Актуальное ядро описано в [Системе аксиом МТС](docs/theory/Система%20аксиом%20МТС.md). Формат каждой карточки задаёт [Шаблон аксиом МТС](docs/theory/Шаблон%20аксиом%20МТС.md).

## Что сейчас стабильно

Практически стабильно:

- постулат "всё есть связь";
- формальная нотация как система смысловых различий;
- три первичные скобочные нотации `(...)`, `[...]`, `{...}`;
- `[]` как пустая форма одной связи;
- `{}` как пустой пучок связей;
- корневой fixture `tests/mtc_formulas.mtc`;
- практические конвертеры UTF-8 и ачисел.

Рабочий слой текущего fixture:

- `(⟼)` как смысл связи и `[⟼]` как конкретная связь;
- абиты квадратной нотации `[`, `]`, `1`, `0`;
- `(=)`, `(!=)`, `¬[]`, `¬[⟼]`, `↛` и `0` фиксируются как рабочие различия текущего fixture и продолжают развиваться в слое развития.

Рабочее и изменяемое:

- полная модель `:`;
- полная модель результата сравнения и типа `[] = []`;
- строгая семантика `↛`;
- связь `0` с сериализацией отсутствия;
- переменные и подстановка как производные механизмы;
- будущий апрувер, который решает систему формул одновременно.

## Где тест формул

Канонический файл формул:

```text
tests/mtc_formulas.mtc
```

Он содержит только формулы МТС и комментарии. В нём нет служебных префиксов `AXIOM`, `EXEC`, `RULE`, `NEGATIVE`, `STATUS`.

Регрессионные проверки проверяют:

- наличие актуальных документов;
- чистый формат `tests/mtc_formulas.mtc`;
- наличие обязательных формул;
- отсутствие вынесенных за пределы ядра внешних механизмов;
- согласованность описания `()`, `[]`, `{}` в активных документах;
- согласованность ссылок README.

```bash
python -m pytest tests -v --tb=short

```

## English Summary

MTS is a theory of links. The current working version treats formal MTS notation as a system of semantic distinctions. Its root formulas describe bracket containers: explicit formal grouping, the empty form of one link, and bundle / aset notation. The canonical formula fixture is `tests/mtc_formulas.mtc`.
