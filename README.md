# Метатеория связей (МТС)

## Что сейчас является МТС

МТС фиксируется постулатом:

```text
всё есть связь
```

связь — единственная форма существования. существовать — значит быть связью.

Смысл не существует отдельно от связи: связь и есть смысл в своей различённой форме. Связь существует между началом и концом, но начало и конец не являются внешними объектами. Это смысловые полюса самой связи.

Корневая система формул является корневой библиотекой апрувера. Документация поясняет текущую систему, а нормативный набор формул хранится в `tests/mtc_formulas.mtc`.

## Онтологическое ядро

```text
связь — единственная форма существования;
существовать — значит быть связью;
смысл не существует отдельно от связи;
связь и есть смысл в своей различённой форме;
несвязь не существует в натуре;
смысл несвязи выражается связью;
акорень несёт смысл смысла.
```

Несвязь не существует в натуре как самостоятельная натуральная форма. Допустим только смысл несвязи, и он тоже выражается связью.

```text
↛ — смысл несвязи
0 — абит связи, несущей смысл несвязи
```

инверсия связи меняет направление натуральной связи. инверсия смысла меняет смысл на обратный. обратное направление связи не является отсутствием связи, и абит 0 не является отсутствием связи в натуре.

## Базовый словарь акорня

```text
∞ : [] = [] ⟼ []
[] = ∞
∞ = ∞ ⟼ ∞

() : ♀() ⟼ ()♂

([) : (♀∞)
(]) : (∞♂)

(⟼) : (♀∞ ⟼ ∞♂)
(↛) : (∞♂ ⟼ ♀∞)

[1] : (⟼)
[0] : (↛)

(=) : {[]♀ = []♀, ♂[] = ♂[]}
```

Чтение:

```text
∞ — акорень, смысл смысла
[] — минимальная завершённая форма одной связи
() — минимальная формальная форма смысла
([) — смысл левого квадратного абита
(]) — смысл правого квадратного абита
(⟼) — смысл связи
(↛) — смысл несвязи
[1] — квадратная форма абита связи
[0] — квадратная форма абита несвязи
```

Равенство фиксирует совпадение форм связей. Равенство не является простой идентичностью определения, формы связей являются видами самозамыканий, рекурсивная процедура сравнения различает формы рекурсий, и равенство не требует бесконечного раскрытия рекурсивных связей.

## Скобочные нотации

```text
(...) — круглая формальная нотация
[...] — квадратная ачисловая нотация
{...} — пучковая нотация
```

```text
[] — минимальная завершённая форма одной связи
() — минимальная формальная форма смысла
{} — пустой пучок связей
```

Скобки не взаимозаменяемы. В `([)` символ `[` является буквальным абитом внутри круглой формальной нотации. В `[1]` символы `[` и `]` являются границами квадратной формы.
