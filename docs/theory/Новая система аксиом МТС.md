# Новая система аксиом МТС

## Статус

Статус: рабочее.

Это ядро после issue #42 не является закрытой финальной системой, но задаёт направление переработки: аксиомы должны описывать виды форм смыслов, а не список частных связей.

## Принципы

1. Каждая аксиома вводит один смысловой механизм.
2. Формула аксиомы является шаблоном поиска формы.
3. Рекурсивность допускается как свойство всей системы, но не должна превращать аксиому в пустую тавтологию.
4. Частные случаи не должны раздувать ядро, если они выражаются через общий вид формы.
5. Ачисла и формальная нотация не смешиваются.

## Минимальное ядро

### 1. Акорень

```text
∞ : {} = {} ⟼ {}
```

Полное самозамыкание. `∞` — знак смысла, найденного по форме, где связь-кандидат тождественна связи самой с собой.

Внутри одного исполнения шаблона все одинаковые вхождения `{}` относятся к одной и той же связи-кандидату. Поэтому эта аксиома ищет один `X`, для которого `X = X ⟼ X`.

После исполнения шаблона:

```text
∞ : ∞ ⟼ ∞
```

### 2. Самозамкнутое начало

```text
♂{} : ♂{} = ♂{} ⟼ {}
```

Вид формы связи, где начало замкнуто на саму форму, а конец остаётся внешним кандидатом.

### 3. Самозамкнутый конец

```text
{}♀ : {}♀ = {} ⟼ {}♀
```

Вид формы связи, где конец замкнут на саму форму, а начало остаётся внешним кандидатом.

### 4. Абиты начала и конца

```text
{[} : ∞♀
{]} : ♂∞
```

`[` и `]` остаются абитами ачисел. В формальной нотации используются их смысловые ссылки `{[}` и `{]}`.

### 5. Смысл конструктора связи

```text
{⟼} : {[} ⟼ {]}
```

Смысл конструктора связи задаётся связью смысла абита начала со смыслом абита конца.

## Что удаляется из ядра

Из актуального ядра убираются:

- отдельные аксиомы для старых скобочных записей связи как самостоятельных форм ядра;
- трактовка `{}` как пустого множества;
- использование `[]` как универсального экранирования;
- переменные `x`, `a`, `b` как будто они являются внутренними символами МТС;
- повторяющиеся частные аксиомы, если они выражаются через вид формы.

## Статус `:` и `=`

В текущем ядре:

```text
: — акт введения знака для смысла, найденного по форме
= — отношение структурной неразличимости после исполнения шаблона
```

Они используются как рабочие механизмы записи, но пока не сведены к отдельным минимальным аксиомам. Это первоочередная задача следующей стабилизации.

## Нерешённые места

Нужно отдельно стабилизировать:

- форму несвязи `{↛}`;
- смысл абитов `0` и `1`;
- отношение `:` и `=`;
- независимые шаблонные поиски в одной формуле;
- исполнение шаблона и результат поиска;
- связь новой нотации с текущими парсерами.

Полный регистр ведётся в [`Открытые вопросы новой аксиоматики МТС`](../research/Открытые%20вопросы%20новой%20аксиоматики%20МТС.md).
