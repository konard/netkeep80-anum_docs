# Метатеория связей (МТС)

## Введение

**Метатеория связей (МТС)** — это формальная система, в которой всё есть связь. Система является онтологически замкнутой: не существует внешних сущностей, которые не могут быть выражены через связи. МТС устраняет традиционный дуализм между «объектами» и «отношениями», сводя их к единой категории — направленным связям.

### Метацель

Создание формальной системы, в которой всё (включая логику, числа, типы, данные) выражается как направленные связи. МТС служит основой для описания структур данных, логических операций и сложных систем через унифицированный язык связей.

### Два ортогональных домена

#### Домен форм связей (теоретический уровень)
- **Назначение**: формальные конструкции, аксиомы, теоремы
- **Содержание**: операторы формальной нотации МТС, паттерны связей, правила вывода
- **Символы**: `⟼`, `∞`, `♂`, `♀`, `¬`, `=`, `:`, переменные
- **Цель**: строгое логическое построение теории

#### Домен сериализации (практический уровень)
- **Назначение**: представление данных в виде последовательностей
- **Содержание**: абиты, ачисла, правила кодирования и декодирования
- **Символы**: `(`, `)`, `+`, `-`
- **Цель**: конкретная реализация, хранение и передача информации

### Принципы построения

1. **Онтологическая замкнутость**: всё выражается через связи, без внешних сущностей
2. **Иконичность**: форма символов отражает их структуру (остенсивность)
3. **Левоассоциативность**: группировка слева направо как принцип построения
4. **Разделение доменов**: строгое разграничение между теорией и практикой
5. **Минимальность**: каждая аксиома вводит ровно одно новое понятие
6. **Конструктивность**: аксиомы описывают как связи строятся, а не только их свойства

### А0. Аксиома определения

```
(s : F) ⟼ (s = F)
```

**Постулат аксиомы.** Акт определения знака `s` формой `F` порождает структурное тождество между знаком и формой.

**Смысл:**
1. **Ключевой принцип:** Знак `s` вводится не как ссылка на связь, а как запрос ко всем связям, удовлетворяющим форме `F`. Определение порождает тождество: после `s : F` выполняется `s = F`.
2. **Особенности структуры:**
   - Ориентированность: `(s : F) ≠ (F : s)` — определяется знак формой, не наоборот.
   - Уникальность: `{s : F, s : G} ⟼ (F = G)` — знак имеет единственную форму.
   - Ограждённая рекурсия: рекурсия допускается только под оператором `⟼`.
3. **Ограничения:**
   - Оператор `:` принадлежит формальной нотации, а не объектному языку.

**Следствия:**
- Каждый символ МТС определён через форму связи.
- Определение и тождество связаны причинно: определение порождает тождество.

**Итог:** Определение — это акт различения формы, связывающий знак и структуру.

### А1. Аксиома тождественности

```
x = x
(x = y) ⟼ (y = x)
{(x = y), (y = z)} ⟼ (x = z)
```

**Постулат аксиомы.** Тождественность — это рефлексивное, симметричное и транзитивное отношение структурной неразличимости связей.

**Смысл:**
1. **Ключевой принцип:** Связи тождественны, если их формы неразличимы в любом контексте. Знак `=` в МТС — иконическое выражение дуальности бытия: две связи тождественны тогда и только тогда, когда их конструкции тождественны.
2. **Особенности структуры:**
   - Рефлексивность: `x = x` — каждая связь тождественна себе.
   - Симметричность: `(x = y) ⟼ (y = x)`.
   - Транзитивность: `{(x = y), (y = z)} ⟼ (x = z)`.
3. **Ограничения:**
   - Тождественность определяется только структурой, не внешними свойствами.

**Следствия:**
- Доказательство тождества сводится к структурному анализу.
- Принцип замены: тождественные связи взаимозаменяемы в любом контексте.

**Итог:** Тождественность — это структурная неразличимость, определяющая когда две связи суть одно.

### А2. Аксиома конгруэнции

```
Для ⟼:
  {(a = c), (b = d)} ⟼ ((a ⟼ b) = (c ⟼ d))
  ((a ⟼ b) = (c ⟼ d)) ⟼ {(a = c), (b = d)}

Для ♂:
  (a = b) ⟼ (♂a = ♂b)
  (♂a = ♂b) ⟼ (a = b)

Для ♀:
  (a = b) ⟼ (a♀ = b♀)
  (a♀ = b♀) ⟼ (a = b)

Для ¬:
  (a = b) ⟼ (¬a = ¬b)
  (¬a = ¬b) ⟼ (a = b)
```

**Постулат аксиомы.** Тождественность сохраняется под всеми конструкторами. Если компоненты связей тождественны, то и сами связи тождественны. Конгруэнция работает в обе стороны: композиция и декомпозиция.

**Смысл:**
1. **Ключевой принцип:** Структурная прозрачность — конструкторы `⟼`, `♂`, `♀`, `¬` не нарушают тождество. Если начала двух связей тождественны и концы тождественны, то и связи тождественны. Обратно: если связи тождественны, то и их компоненты тождественны.
2. **Особенности структуры:**
   - Работает в обе стороны: композиция и декомпозиция.
   - Распространяется на все четыре конструктора: `⟼`, `♂`, `♀`, `¬`.
   - Декомпозиция позволяет извлекать равенство компонентов из равенства целых связей.
3. **Ограничения:**
   - Конгруэнция — следствие структурной природы тождества, не дополнительное допущение.

**Следствия:**
- Можно заменять компоненты связей на тождественные без изменения результата.
- Основа для структурной индукции по связям.

**Итог:** Конгруэнция гарантирует, что тождество сохраняется при конструировании и позволяет декомпозировать равенство.

### А3. Аксиома связи

```
rv : r ⟼ v
```

**Постулат аксиомы.** Всякое существование есть направленная связь между началом `r` и концом `v`.

**Смысл:**
1. **Ключевой принцип:** Связь — фундаментальная единица бытия. Любая связь `rv` определяется как направленное отношение от начала `r` к концу `v`. Не существует изолированных сущностей — всё структурировано как направленные связи.
2. **Особенности структуры:**
   - Бинарность: каждая связь имеет ровно два компонента — начало и конец.
   - Направленность: `r ⟼ v` структурно отлично от `v ⟼ r`.
   - Оператор `⟼` иконически отражает направление от начала к концу.
   - Нетранзитивность: из `a ⟼ b` и `b ⟼ c` не следует `a ⟼ c`.
3. **Ограничения:**
   - Связи без направления не существуют.
   - Связи с более чем двумя компонентами не определены.

**Следствия:**
- Всякая сущность может быть выражена как связь.
- Начало и конец — единственные структурные компоненты связи.

**Итог:** Бытие есть связь. Это фундаментальный принцип, делающий МТС онтологически замкнутой системой.

### А4. Аксиома смысла

```
∞ : ∞ ⟼ ∞
```

**Постулат аксиомы.** `∞` есть смысл. Смысл есть связь смыслов: `∞ : ∞ ⟼ ∞`. Это онтологический якорь системы — единственная связь, тождественная связи самой с собой.

**Смысл:**
1. **Ключевой принцип:** `∞` определяется как связь, связанная сама с собой: `∞ = ∞ ⟼ ∞`. Смысл — это не внешнее свойство, а сама структура самозамкнутой связи. Никакая другая связь не обладает этим свойством. `∞` — онтологический якорь, из которого строятся все остальные связи.
2. **Особенности структуры:**
   - Самотождественность: `∞ = ∞ ⟼ ∞` — смысл есть связь смыслов.
   - Уникальность: если `x = x ⟼ x`, то `x = ∞`.
   - Символ `∞` иконически отражает бесконечную самоссылку смысла.
   - Идемпотентность: `∞ⁿ = ∞` для любого n.
   - Самодуальность: `¬∞ = ∞`.
3. **Ограничения:**
   - `∞` не является абитом и не входит в ачисла.
   - Других полностью самозамкнутых связей не существует.

**Следствия:**
- `∞` — единственная константа системы, онтологический якорь.
- Все конструкции МТС строятся от `∞`.
- Из `∞` возникают четыре базовые формы: `♂∞`, `∞♀`, `+`, `-`.
- Рекурсивные определения имеют `∞` как базовый случай.

**Итог:** `∞` есть смысл, смысл есть связь смыслов — это онтологический якорь, точка отсчёта всех связей в МТС.

### А5. Аксиома самозамыкания по началу

```
♂v : ♂v ⟼ v
```

**Постулат аксиомы.** Оператор `♂` определяет связь с самозамкнутым началом. `♂v` — это связь, начало которой равно ей самой, а конец равен `v`.

**Смысл:**
1. **Ключевой принцип:** `♂v` создаёт безначальную связь — связь, у которой начало замкнуто само на себя. Поскольку начало отсутствует как самостоятельная сущность, смысл `♂v` — это конец связи, то есть `v`. Оператор `♂` извлекает конец связи:
   - `♂(ab) = b` — применение `♂` к связи `ab` возвращает её конец `b`.
2. **Особенности структуры:**
   - `♂v` порождает рекурсивную структуру: `♂v = (♂v) ⟼ v`.
   - Является унарным правоассоциативным оператором: `♂♂v ≡ ♂(♂v)`.
   - Символ `♂` иконически отражает замкнутость начала (петля сверху).
3. **Ограничения:**
   - `♂` применяется только к связям.

**Следствия:**
- Определение абита `(`: `( : ♂∞` (начало смысла).
- Возможность построения вложенных структур.

**Итог:** Оператор `♂` конструирует безначальную связь и извлекает конец связи.

### А6. Аксиома самозамыкания по концу

```
r♀ : r ⟼ r♀
```

**Постулат аксиомы.** Оператор `♀` определяет связь с самозамкнутым концом. `r♀` — это связь, конец которой равен ей самой, а начало равно `r`.

**Смысл:**
1. **Ключевой принцип:** `r♀` создаёт бесконечную связь — связь, у которой конец замкнут сам на себя. Поскольку конец отсутствует как самостоятельная сущность, смысл `r♀` — это начало связи, то есть `r`. Оператор `♀` извлекает начало связи:
   - `(ab)♀ = a` — применение `♀` к связи `ab` возвращает её начало `a`.
2. **Особенности структуры:**
   - `r♀` порождает рекурсивную структуру: `r♀ = r ⟼ (r♀)`.
   - Является унарным левоассоциативным оператором: `r♀♀ ≡ (r♀)♀`.
   - Символ `♀` иконически отражает замкнутость конца (петля снизу).
3. **Ограничения:**
   - `♀` применяется только к связям.

**Следствия:**
- Определение абита `)`: `) : ∞♀` (конец смысла).
- Возможность построения вложенных структур.

**Итог:** Оператор `♀` конструирует бесконечную связь и извлекает начало связи.

### А7. Аксиома инверсии

```
¬(a ⟼ b) = b ⟼ a
¬(♂v) = v♀
¬(r♀) = ♂r
¬∞ = ∞
¬¬x = x
```

**Постулат аксиомы.** Инверсия связи меняет местами начало и конец, обращая направление. Инверсия — это не отрицание существования, а переконфигурация структуры.

**Смысл:**
1. **Ключевой принцип:** Оператор `¬` инвертирует направление связи. Если связь идёт от `a` к `b`, то её инверсия идёт от `b` к `a`. Инверсия устанавливает дуальность между операторами замыкания:
   - `¬(♂v) = v♀` — инверсия безначальной связи даёт бесконечную связь.
   - `¬(r♀) = ♂r` — инверсия бесконечной связи даёт безначальную связь.
   - `¬∞ = ∞` — инверсия акорня даёт акорень (самодуальность).
2. **Особенности структуры:**
   - Инволюция: `¬¬x = x` — двойная инверсия возвращает к исходному.
   - Символ `¬` обозначает смену направления связи.
   - Инверсия применима к любой связи.
3. **Ограничения:**
   - Из `a ⟼ b` и `b ⟼ c` не следует `a ⟼ c` (запрет транзитивности).

**Следствия:**
- Двойная инверсия возвращает к исходному: `¬(¬(a ⟼ b)) = a ⟼ b`.
- Инверсия распределяется по последовательности: `¬(a ⟼ b ⟼ c) = c ⟼ b ⟼ a`.
- Определение инверсии через операторы: `¬(ab) = ♂(ab) ⟼ (ab)♀`, то есть `b ⟼ a`.
- Нотация `¬⟼` (в aprover: `!->`) — синтаксический сахар для отрицания стрелки: `a ¬⟼ b ≡ ¬(a ⟼ b)`.

**Итог:** Инверсия — операция обращения направления, обеспечивающая структурную дуальность МТС.

### А8. Аксиома единицы смысла

```
+ : ♂∞ ⟼ ∞♀
```

**Постулат аксиомы.** Единица смысла `+` — это направленная связь от начала смысла (`♂∞`) к концу смысла (`∞♀`). Это минимальная структура, в которой различение начала и конца реализуется полноценно.

**Смысл:**
1. **Ключевой принцип:** `+` — направленная связь от самозамкнутого начала к самозамкнутому концу. Это единица, из которой строится вся семантика МТС. В `+` начало и конец различены максимально.
2. **Особенности структуры:**
   - `+` соединяет два полуоткрытых полюса акорня.
   - Является основой для кодирования истинностных значений (наличие, утверждение).
3. **Ограничения:**
   - `+` — производная константа, определяемая через `♂∞` и `∞♀`.

**Следствия:**
- `+` — основа 4-значной «алогики» вместе с `-`, `♂∞` и `∞♀`.
- Используется как абит для сериализации.

**Итог:** Единица смысла — минимальная связь с полным различением начала и конца.

---

### А9. Аксиома нуля смысла

```
- : ¬+
```

**Постулат аксиомы.** Нуль смысла `-` — это инверсия единицы смысла. `- = ∞♀ ⟼ ♂∞`.

**Смысл:**
1. **Ключевой принцип:** `-` определяется как `¬+`, то есть связь от конца смысла (`∞♀`) к началу смысла (`♂∞`). Это инверсия направления единицы смысла — обратный ход от конца к началу.
2. **Особенности структуры:**
   - `¬+ = ¬(♂∞ ⟼ ∞♀) = ∞♀ ⟼ ♂∞ = -`.
   - `¬- = +` — двойная инверсия возвращает к единице.
3. **Ограничения:**
   - `-` — производная константа, определяемая через инверсию `+`.

**Следствия:**
- Пара `+`/`-` образует дуальность наличия/отсутствия.
- Используется как абит для сериализации.

**Итог:** Нуль смысла — инверсия единицы, замыкающая дуальную пару семантических констант.

---

### А10. Аксиома абитов

```
( : ♂∞
) : ∞♀
+ : +
- : -
```

**Постулат аксиомы.** Четыре элементарные связи — **абиты** (ассоциативные биты) — определяют четверичную систему сериализации связей.

**Смысл:**
1. **Ключевой принцип:** Абиты — четыре базовые формы связей вокруг акорня, формирующие элементарные «строительные блоки» ассоциативной памяти:
   - `(` — начало смысла (`♂∞`): самозамкнутое начало акорня
   - `)` — конец смысла (`∞♀`): самозамкнутый конец акорня
   - `+` — единица смысла (`♂∞ ⟼ ∞♀`): направленная связь от начала к концу
   - `-` — нуль смысла (`∞♀ ⟼ ♂∞`): инверсия единицы
2. **Особенности структуры:**
   - Ровно четыре абита — четверичная система.
   - Каждый абит — конкретная связь вокруг акорня `∞`.
3. **Ограничения:**
   - `∞` не является абитом — это метатеоретический конструкт, выражаемый через комбинацию абитов.

**Следствия:**
- Любая связь может быть сериализована в последовательность абитов (ачисло).

**Итог:** Абиты — мост между доменом форм связей и доменом сериализации.

---

### А11. Аксиома левоассоциативности

```
abc = (a ⟼ b) ⟼ c
a(bc) ≠ (a ⟼ b) ⟼ c
```

**Постулат аксиомы.** Последовательность связей группируется слева направо. Правоассоциативная группировка даёт нетождественный результат.

**Смысл:**
1. **Ключевой принцип:** При записи последовательности `abc` группировка производится слева направо: сначала связываются `a` и `b`, затем результат связывается с `c`. Это онтологический принцип построения сложных структур из простых — каждая новая связь присоединяется к результату предыдущего акта связывания.
2. **Особенности структуры:**
   - Последовательность: обработка слева направо.
   - Группировка: каждая пара связывается перед добавлением следующего элемента.
   - `a(bc) ≠ abc` — правоассоциативная группировка явно нетождественна левоассоциативной.
3. **Ограничения:**
   - Правоассоциативная группировка не допускается без явного указания скобками.

**Следствия:**
- Предсказуемый порядок построения структур: `abcd = ((a ⟼ b) ⟼ c) ⟼ d`.
- Основа для алгоритмов сериализации и десериализации.

**Итог:** Левоассоциативность — принцип последовательного построения сложности из простоты.

## Ачисла (ассоциативные числа)

**Ачисло** — это конечная последовательность абитов, являющаяся уникальным идентификатором связи, который можно использовать как ссылку на связь.

### Формы представления

```
Полная форма:    ачисло = абит₁ абит₂ ... абитₙ
Строковая форма: ачисло = "абит₁абит₂...абитₙ"
Четверичная:     ачисло = (q₁, q₂, ..., qₙ), где qᵢ ∈ {0, 1, 2, 3}
```

### Операции

**Конкатенация:** `ачисло₁ ⊕ ачисло₂ = абит₁...абитₘ абит₁'...абитₙ'`

**Инверсия:** `¬(ачисло) = ¬(абит₁...абитₙ) = (¬абит₁)...(¬абитₙ)`

**Длина:** `|ачисло| = количество абитов`

---

## Теоремы

### Теорема 1. Слияние рекурсий

```
♂♀ = ∞
```

**Доказательство:**
1. По аксиоме А5: `♂♀ = (♂♀) ⟼ ♀`.
2. По аксиоме А6: `♂♀ = ♂ ⟼ (♂♀)`.
3. Из (1) и (2): начало `♂♀` равно `♂♀`, конец `♂♀` равен `♂♀`.
4. Следовательно: `♂♀ = (♂♀) ⟼ (♂♀)`.
5. По аксиоме А4 и А2: связь формы `x = x ⟼ x` единственна и есть `∞`.
6. Поэтому: `♂♀ = ∞`.

**Смысл:** Полное слияние рекурсий по началу и концу порождает акорень.

---

### Теорема 2. Двойная инверсия

```
¬(¬(a ⟼ b)) = a ⟼ b
```

**Доказательство:**
1. По аксиоме А7: `¬(a ⟼ b) = b ⟼ a`.
2. Применяя инверсию повторно: `¬(b ⟼ a) = a ⟼ b`.
3. Следовательно: `¬(¬(a ⟼ b)) = a ⟼ b`.

**Смысл:** Двойная инверсия направления возвращает к исходной связи — принцип обратимости.

---

### Петля

```
aa : a ⟼ a
```

Петля — это связь, начало и конец которой равны одной и той же связи `a`. Петля отличается от полного самозамыкания (А4): в петле `a ⟼ a` связь `a` указывает сама на себя, но `a` не обязательно равна `a ⟼ a`. Если `a = a ⟼ a`, то по А4 следует `a = ∞`.

Степень петли: `a² = aa = a ⟼ a`, `a³ = aaa = (a ⟼ a) ⟼ a`.

## Три нотации МТС

МТС определяет три ортогональных способа записи выражений:

### 1. Формальная нотация (`.mtl`)

Язык запросов по форме связей — основной язык теории, который читает прувер.

| Символ | Описание |
|--------|----------|
| `∞` | Акорень (полное самозамыкание) |
| `♂ ...` | Самозамыкание начала (префиксный) |
| `... ♀` | Самозамыкание конца (постфиксный) |
| `a ⟼ b` | Связь от начала `a` к концу `b` (левоассоциативно) |
| `a ¬⟼ b` | Отрицание стрелки: `¬(a ⟼ b)` (синтаксический сахар) |
| `¬t` | Инверсия (унарный префикс) |
| `s : F` | Определение знака `s` формой `F` |
| `A = B` | Тождественность (структурная неразличимость) |
| `A ≠ B` | Отрицание тождества |
| `{ ... }` | Пакет (контейнер множества выражений) |

**Принцип:** Даже `(s : F)` и `(A = B)` — объекты системы, которые можно связывать через `⟼`.

### 2. Строковые ачисла (`.astr`)

UTF-8 представление: каждый символ `c` вводится формально через `'c' : T`, затем строка `c₁c₂...cₙ` интерпретируется как левоассоциативная цепочка:

```
decode(c₁...cₙ) = (((∞ ⟼ c₁) ⟼ c₂) ⟼ ... ⟼ cₙ)
```

### 3. Четверичная (абитовая) нотация (`.anum`)

Алфавит ровно из 4 символов: `(`, `)`, `+`, `-` (в aprover: `[`, `]`, `1`, `0`).

Допускаются вложенные контексты: `( ... )`.

Результат абитового парсинга конвертируется в формальные термы через определения абитов (А10).

## EBNF формальной нотации

Лексические соглашения: пробелы/переводы строк — разделители; комментарии от `//` до конца строки.

```ebnf
File      ::= { Stmt } ;
Stmt      ::= Expr [ "," ] ;
Expr      ::= DefExpr | EqExpr | NeqExpr | Term ;
DefExpr   ::= Term ":" Term ;
EqExpr    ::= Term "=" Term ;
NeqExpr   ::= Term ("≠" | "¬=") Term ;
Term      ::= Chain ;
Chain     ::= Pref { ("⟼" | "¬⟼") Pref } ;
Pref      ::= { "¬" | "♂" } Post ;
Post      ::= Atom { "♀" | Pow } ;
Pow       ::= "^" Nat ;
Atom      ::= Const | Id | AbitLit | StringLit | Set | "(" Expr ")" ;
Set       ::= "{" Expr { "," Expr } "}" ;
Const     ::= "∞" | "+" | "-" ;
AbitLit   ::= "'" { AbitChar } "'" ;
AbitChar  ::= "(" | ")" | "+" | "-" ;
StringLit ::= '"' { Utf8Char } '"' ;
Id        ::= Letter { Letter | Digit | "_" } ;
Nat       ::= Digit { Digit } ;
```

**Примечание:** EBNF приведён в нотации anum_docs. В aprover используется синтаксис `->`, `!->`, `!`, `[`, `]`, `0`, `1` — см. таблицу соответствия.

## Ядро прувера

### Правило вывода

Единственный фундаментальный шаг вывода — **Modus Ponens (MP)**:

> Если доказано `P` и существует выражение `(P ⟼ Q)`, то доказано `Q`.

Вся логика (равенство, симметрия, транзитивность, конгруэнция, свойства `:`) задаётся не встроенными правилами, а аксиомами, которые создают нужные связи `P ⟼ Q`.

### Нормализация

- `¬⟼`: синтаксический сахар — `a ¬⟼ b` нормализуется в `¬(a ⟼ b)`.
- Степени `^n`: синтаксический сахар — `a^1 = a`, `a^(n+1) = (aⁿ ⟼ a)`.

### Ограждённая рекурсия

Для определений `(s : F)`: рекурсивное упоминание `s` в `F` разрешено только под конструктором `⟼`.

## Заключение

Метатеория связей представляет собой онтологически замкнутую формальную систему из 12 аксиом (А0–А11), в которой всё бытие выражается через направленные связи. Разделение на домен форм связей и домен сериализации обеспечивает как теоретическую строгость, так и практическую применимость.

Система МТС является:
- **Минималистичной** — основана на едином операторе `⟼` и 12 аксиомах
- **Универсальной** — выражает логику, числа, типы, данные
- **Вычислимой** — пригодна для реализации в ассоциативной памяти
- **Иконичной** — символы отражают структуру связей
- **Онтологически замкнутой** — все конструкции выражаются через связи
