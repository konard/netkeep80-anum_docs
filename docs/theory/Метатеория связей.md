# Метатеория связей

Статус: актуальное.

## 1. Базовый постулат

```text
всё есть связь
```

МТС не вводит внешнюю область объектов, свойств или множеств. Любая различимая вещь должна быть понята как связь, смысл связи, знак смысла или способ записи формы связи.

## 2. Формальная нотация как система различий

Формальная нотация МТС — система смысловых различий. Она работает с формами связей и описывает другие нотации как способы чтения контейнеров.

```text
строковое ачисло
→ последовательность различий
→ формула
→ интерпретация формулы
→ связь / асеть связей
```

Формула не является просто строкой текста. Строка является носителем записи, а формула является прочитанной последовательностью различий.

## 3. Аксиомы и апрувер

Каждая аксиома имеет собственную формулу формальной нотации МТС.

```text
аксиома = формула
```

Система формул аксиом решается одновременно. Эта система составляет корневую библиотеку апрувера. Документация поясняет формулы, но не заменяет их.

Если у утверждения нет формулы, оно остаётся пояснением или открытым вопросом и не входит в корневую библиотеку как аксиома.

## 4. Первичные скобочные нотации

```text
(...) — явная формальная форма / группировка формы
[...] — нотация ачисла; форма одной связи
{...} — пучковая нотация; форма пучка / асети связей
```

Скобки являются границами контейнера. Контейнер является областью чтения данной нотации. Нотация задаёт способ интерпретации различий внутри контейнера.

## 5. Корневые формулы

```text
∞ : [] = [] ⟼ []
[] = ∞
∞ = ∞ ⟼ ∞

([]) = []
([][]) = [][]
([] ⟼ []) = [] ⟼ []

[][] : [] ⟼ []
[][] = [] ⟼ []

[][][] : ([][]) ⟼ []
[][][] = ([] ⟼ []) ⟼ []
[][][] = [] ⟼ [] ⟼ []

[]([][]) : [] ⟼ ([][])
[][][] != []([][])
[][][] != [] ⟼ ([] ⟼ [])

♂[] : ♂[] = ♂[] ⟼ []
♂∞ = ♂∞ ⟼ ∞

[]♀ : []♀ = [] ⟼ []♀
∞♀ = ∞ ⟼ ∞♀

∞♀ : [⟼]♀
♂∞ : ♂[⟼]

(⟼) : [] ⟼ []
[⟼] : ∞♀ ⟼ ♂∞

¬[] : ♂[] ⟼ []♀
¬[⟼] : ♂[⟼] ⟼ [⟼]♀
¬[⟼] : ♂∞ ⟼ ∞♀

(=) : {[]♀ = []♀, ♂[] = ♂[]}
(!=) : ¬(=)
[] != [] : ¬([] = [])

↛ : ¬[⟼]

[ : ∞♀
] : ♂∞
1 : [⟼]
0 : [↛]

{} != []
{[]} != []
{[], []} = {[]}
{[], [][]} = {[][], []}

[]{[], [][]} = {[] ⟼ [], [] ⟼ [][]}
{[], [][]}[] = {[] ⟼ [], [][] ⟼ []}
{[], [][]}{[], [][]} = {[] ⟼ [], [] ⟼ [][], [][] ⟼ [], [][] ⟼ [][]}
```

Нормативные карточки этих формул и таблица различий находятся в [Системе аксиом МТС](Система%20аксиом%20МТС.md).

## 6. Связь, инверсия, сравнение и абиты

Корневая система различает смысл связи и конкретную связь:

```text
(⟼) : [] ⟼ []
[⟼] : ∞♀ ⟼ ♂∞
```

Инверсия формы связи и конкретной связи фиксируется формулами:

```text
¬[] : ♂[] ⟼ []♀
¬[⟼] : ♂∞ ⟼ ∞♀
```

Равенство вводится через совпадение начал и концов, а неравенство как инверсия смысла равенства:

```text
(=) : {[]♀ = []♀, ♂[] = ♂[]}
(!=) : ¬(=)
```

Абиты квадратной нотации вводятся как `[`, `]`, `1`, `0`. `∞` не является абитом.

## 7. Что не входит в актуальное ядро

В актуальное ядро не входят:

- универсальный внешний placeholder;
- смысловая запись для отдельного знака другой нотации;
- нормативная внешняя грамматика;
- переменные как первичный механизм;
- подстановка;
- полная модель результата сравнения;
- строгая семантика `↛`;
- полная модель `:`;
- операционное удаление в пучковой нотации;
- пустое `()` как самостоятельная форма.

Эти темы ведутся в [Открытых вопросах новой аксиоматики МТС](../research/Открытые%20вопросы%20новой%20аксиоматики%20МТС.md).
