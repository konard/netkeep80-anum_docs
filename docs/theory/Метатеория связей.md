# Метатеория связей

Статус: актуальное, нормативное изложение.

## Тезис

МТС исходит из постулата:

```text
всё есть связь
```

связь — единственная форма существования. существовать — значит быть связью. Смысл не существует отдельно от связи: связь и есть смысл в своей различённой форме.

## Натуральная связь и смысловая роль

Натуральная связь существует между началом и концом. Начало и конец не являются внешними объектами, а читаются как полюса связи.

Смысловая роль появляется, когда та же связь читается как форма смысла. Это не вводит отдельную сущность смысла.

```text
натуральная связь — связь как существующая форма;
смысловая роль — связь как различённый смысл.
```

## Акорень и словарь

Акорень несёт смысл смысла:

```text
∞ : [] = [] ⟼ []
[] = ∞
∞ = ∞ ⟼ ∞
```

Вокруг акорня фиксируется базовый словарь:

```text
() : ♀() ⟼ ()♂
([) : (♀∞)
(]) : (∞♂)
(⟼) : (♀∞ ⟼ ∞♂)
(↛) : (∞♂ ⟼ ♀∞)
[1] : (⟼)
[0] : (↛)
```

`[]` — минимальная завершённая форма одной связи. `()` — минимальная формальная форма смысла. `{}` — пустой пучок связей.

## Несвязь

Несвязь не существует в натуре. Смысл несвязи выражается связью.

```text
↛ — смысл несвязи
0 — абит связи, несущей смысл несвязи
```

Абит 0 не является отсутствием связи в натуре. Он является квадратной формой абита, которая несёт смысл несвязи через формулу `[0] : (↛)`.

## Инверсия

Инверсия связи меняет направление натуральной связи. Инверсия смысла меняет смысл на обратный.

Обратное направление связи не является отсутствием связи.

```text
♀∞ ⟼ ∞♂ — связь, несущая смысл связи
∞♂ ⟼ ♀∞ — связь, несущая смысл несвязи
```

## Равенство

Равенство фиксирует совпадение форм связей:

```text
(=) : {[]♀ = []♀, ♂[] = ♂[]}
```

Равенство не является простой идентичностью определения. Формы связей являются видами самозамыканий. Рекурсивная процедура сравнения различает формы рекурсий, поэтому равенство не требует бесконечного раскрытия рекурсивных связей.

## Нотации

```text
(...) — круглая формальная нотация
[...] — квадратная ачисловая нотация
{...} — пучковая нотация
```

Круглая нотация вводит и группирует формальные смыслы. Квадратная нотация задаёт форму одной связи и абитовые формы. Пучковая нотация задаёт пучок связей.
