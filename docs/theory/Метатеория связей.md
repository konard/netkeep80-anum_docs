# Метатеория связей (МТС)

## Введение

**Метатеория связей (МТС)** — это формальная система, в которой всё есть связь. Система является онтологически замкнутой: не существует внешних сущностей, которые не могут быть выражены через связи. МТС устраняет традиционный дуализм между «объектами» и «отношениями», сводя их к единой категории — направленным связям.

### Метацель

Создание формальной системы, в которой всё (включая логику, числа, типы, данные) выражается как направленные связи. МТС служит основой для описания структур данных, логических операций и сложных систем через унифицированный язык связей.

### Два ортогональных домена

#### Домен форм связей (теоретический уровень)
- **Назначение**: формальные конструкции, аксиомы, теоремы
- **Содержание**: операторы формальной нотации МТС, паттерны связей, правила вывода
- **Символы**: `⟼`, `∞`, `♂`, `♀`, `¬`, `=`, `:`, переменные
- **Цель**: строгое логическое построение теории

#### Домен сериализации (практический уровень)
- **Назначение**: представление данных в виде последовательностей
- **Содержание**: абиты, ачисла, правила кодирования и декодирования
- **Символы**: `[`, `]`, `1`, `0`
- **Цель**: конкретная реализация, хранение и передача информации

### Принципы построения

1. **Онтологическая замкнутость**: всё выражается через связи, без внешних сущностей
2. **Иконичность**: форма символов отражает их структуру (остенсивность)
3. **Левоассоциативность**: группировка слева направо как принцип построения
4. **Разделение доменов**: строгое разграничение между теорией и практикой
5. **Минимальность**: каждая аксиома вводит ровно одно новое понятие
6. **Конструктивность**: аксиомы описывают как связи строятся, а не только их свойства
7. **Самозамкнутость системы аксиом**: аксиоматика МТС представляет собой самозамкнутую систему логических уравнений — формула аксиомы может рекурсивно использовать как саму себя, так и другие аксиомы; система не решается по частям, все аксиомы взаимозависимы и обретают смысл только в совокупности

### А0. Аксиома определения

**Формально-математическое определение:**

```
(s : F) ⟼ (s = F)
```

**Содержательно-онтологическое определение:**

Определение — это связь, в которой начало есть знак (ссылка), а конец есть форма (значение). Акт определения знака `s` формой `F` порождает структурное тождество между знаком и формой. Определение само является связью: его начало `s` и конец `F` определяют смысл определения в силу аксиомы смысла (А4).

Знак `s` не ссылается на конкретную связь — он задаёт паттерн поиска (запрос по форме) ко всем связям в асети, удовлетворяющим форме `F`. Паттерн формы и его резолюция возникают синхронно в едином акте онтологического различения.

**Остенсивное определение:**

```
s : F — знак s определяется формой F, порождая тождество s = F

     (s : F)
      /    \
  знак s   форма F
 (начало)  (конец)
```

Определение — связь от знака к форме: `s` (начало, ссылка) определяется через `F` (конец, значение). Оператор `:` есть конструктор акта различения формы.

**Смысл:**
1. **Ключевой принцип:** Аксиома определения определяет, что такое определение. Определение — это связь, и как всякая связь (А3), оно имеет начало и конец. Начало определения — знак `s` (ссылка), конец определения — форма `F` (значение). Начало и конец определения задают его смысл как направленное отношение от знака к форме. Знак `s` вводится не как ссылка на конкретную связь, а как запрос ко всем связям, удовлетворяющим форме `F`. Определение порождает тождество: после `s : F` выполняется `s = F`.
2. **Особенности структуры:**
   - Ориентированность: `(s : F) ≠ (F : s)` — определяется знак формой, не наоборот.
   - Уникальность: `{s : F, s : G} ⟼ (F = G)` — знак имеет единственную форму.
   - Ограждённая рекурсия: рекурсия допускается только под оператором `⟼`.
   - Синхронность: паттерн формы и его резолюция возникают одновременно — нет цикла «имя → объект → имя».
3. **Ограничения:**
   - Оператор `:` принадлежит формальной нотации, а не объектному языку.

**Следствия:**
- Каждый символ МТС определён через форму связи.
- Определение и тождество связаны причинно: определение порождает тождество.
- Определение есть связь: его начало (знак) и конец (форма) определяют смысл определения.
- Знак и связь существуют в одном онтологическом поле различений — разрыв между знаком и связью устраняется.

**Итог:** Аксиома определения определяет, что такое определение. Определение — это связь от знака к форме, акт различения, в котором знак задаёт паттерн поиска по форме связей. Начало определения (знак) и конец определения (форма) определяют его смысл.

### А1. Аксиома тождественности

**Формально-математическое определение:**

```
x = x
(x = y) ⟼ (y = x)
{(x = y), (y = z)} ⟼ (x = z)
```

**Содержательно-онтологическое определение:**

Тождественность — это рефлексивное, симметричное и транзитивное отношение структурной неразличимости связей. Связи равны по смыслу, если они равны по определению.

**Остенсивное определение:**

```
= — знак структурной неразличимости: две параллельные линии,
    иконически отражающие симметрию тождества
```

**Смысл:**
1. **Ключевой принцип:** Связи тождественны, если их формы неразличимы в любом контексте. Знак `=` в МТС — иконическое выражение дуальности бытия: две связи тождественны тогда и только тогда, когда их конструкции тождественны.
2. **Особенности структуры:**
   - Рефлексивность: `x = x` — каждая связь тождественна себе.
   - Симметричность: `(x = y) ⟼ (y = x)`.
   - Транзитивность: `{(x = y), (y = z)} ⟼ (x = z)`.
3. **Ограничения:**
   - Тождественность определяется только структурой, не внешними свойствами.

**Следствия:**
- Доказательство тождества сводится к структурному анализу.
- Принцип замены: тождественные связи взаимозаменяемы в любом контексте.

**Итог:** Тождественность — это структурная неразличимость, определяющая когда две связи суть одно.

### А2. Аксиома конгруэнции

**Формально-математическое определение:**

```
Для ⟼:
  {(a = c), (b = d)} ⟼ ((a ⟼ b) = (c ⟼ d))
  ((a ⟼ b) = (c ⟼ d)) ⟼ {(a = c), (b = d)}

Для ♂:
  (a = b) ⟼ (♂a = ♂b)

Для ♀:
  (a = b) ⟼ (a♀ = b♀)

Для ¬:
  (a = b) ⟼ (¬a = ¬b)
  (¬a = ¬b) ⟼ (a = b)
```

**Содержательно-онтологическое определение:**

Тождественность сохраняется под всеми конструкторами. Если компоненты связей тождественны, то и сами связи тождественны. Для бинарного конструктора `⟼` и инверсии `¬` конгруэнция работает в обе стороны (композиция и декомпозиция). Для унарных операторов `♂` и `♀` конгруэнция работает только в одну сторону: из равенства аргументов следует равенство результатов, но не наоборот.

**Остенсивное определение:**

```
{(a = c), (b = d)} ⟼ ((a ⟼ b) = (c ⟼ d)) — если части равны, то и целое равно
((a ⟼ b) = (c ⟼ d)) ⟼ {(a = c), (b = d)} — если целое равно, то и части равны
```

**Смысл:**
1. **Ключевой принцип:** Структурная прозрачность — конструкторы `⟼`, `♂`, `♀`, `¬` не нарушают тождество. Если компоненты связей тождественны, то и сами связи тождественны.
2. **Особенности структуры:**
   - Для `⟼` и `¬` конгруэнция работает в обе стороны: композиция и декомпозиция.
   - Для `♂` и `♀` конгруэнция работает только в одну сторону: из равенства аргументов следует равенство результатов, но обратное неверно (♂ извлекает конец, ♀ извлекает начало — разные связи могут иметь одинаковый конец или начало).
   - Распространяется на все четыре конструктора: `⟼`, `♂`, `♀`, `¬`.
3. **Ограничения:**
   - Конгруэнция — следствие структурной природы тождества, не дополнительное допущение.

**Следствия:**
- Можно заменять компоненты связей на тождественные без изменения результата.
- Основа для структурной индукции по связям.

**Итог:** Конгруэнция гарантирует, что тождество сохраняется при конструировании. Для `⟼` и `¬` конгруэнция также позволяет декомпозировать равенство. Для `♂` и `♀` обратная декомпозиция неверна.

### А3. Аксиома связи

**Формально-математическое определение:**

```
rv : r ⟼ v
```

**Содержательно-онтологическое определение:**

Связь — это неделимая тройственность: начало `r`, конец `v` и сама связь `rv` возникают синхронно в одном акте. Связь не конструируется из начала и конца — нет «сначала начало и конец, потом связь». Знак `rv` обозначает связь, форма которой `r ⟼ v`. Оператор `⟼` — фундаментальный конструктор существования.

Формула `rv : r ⟼ v` не является правилом сокращения записи. Это онтологический постулат: всякое существование есть направленная связь от начала к концу. Запись `rv` и запись `r ⟼ v` выражают два аспекта одного и того же: `rv` — связь как целостность, `r ⟼ v` — связь как структура с направлением.

**Остенсивное определение:**

```
r ——⟼ v — стрелка от начала r к концу v,
           иконически выражающая направленность связи

    rv
   /  \
  r    v
```

Графическая форма стрелки `⟼` остенсивно отражает направленность от начала к концу. Треугольник показывает неделимость: связь `rv` не распадается на отдельные `r` и `v`.

**Смысл:**
1. **Ключевой принцип:** Связь — первичная онтологическая категория. Формула `rv : r ⟼ v` утверждает, что любая связь `rv` определяется как направленное отношение от начала `r` к концу `v`. Это не правило нотации, а фундаментальный постулат бытия: не существует изолированных сущностей — всё структурировано как направленные связи.
   - Отличие от правила сокращения: правило нотации устанавливает синтаксическую эквивалентность двух записей. А3 устанавливает, что `⟼` является единственным способом существования — бинарным оператором, создающим новую связь из двух существующих.
   - Отличие от аксиомы связи (А7): А7 определяет конкретную связь `(⟼) : ∞♀ ⟼ ♂∞` — направленную связь от начала к концу смысла. А3 определяет сам конструктор `⟼`, из которого строятся все связи, включая `(⟼)`.
2. **Особенности структуры:**
   - Бинарность: каждая связь имеет ровно два компонента — начало и конец.
   - Направленность: `r ⟼ v` структурно отлично от `v ⟼ r`.
   - Оператор `⟼` иконически отражает направление от начала к концу.
   - Нетранзитивность: из `a ⟼ b` и `b ⟼ c` не следует `a ⟼ c`.
   - `⟼` существует только как оператор, не как отдельная связь (константа).
3. **Ограничения:**
   - Связи без направления не существуют.
   - Связи с более чем двумя компонентами не определены.
   - Нельзя менять местами начало и конец без инверсии (А14).

**Следствия:**
- Всякая сущность может быть выражена как связь.
- Начало и конец — единственные структурные компоненты связи.
- `⟼` служит базовым конструктором для построения всех сложных связей (А4–А16 используют `⟼` для определения).
- Направленность `⟼` определяет фундаментальную асимметрию в МТС.

**Итог:** А3 — не сокращение нотации, а онтологический постулат: бытие есть связь. Оператор `⟼` — единственный способ конструирования существования. Это делает МТС онтологически замкнутой системой, в которой нет «объектов» вне связей.

### А4. Аксиома смысла

**Формально-математическое определение:**

```
∞ : ∞ ⟼ ∞
```

**Содержательно-онтологическое определение:**

Смысл определяется связью смысла со смыслом. `∞` есть смысл. Смысл есть форма полного самозамыкания связи: `∞ : ∞ ⟼ ∞`. Это онтологический якорь системы — единственная связь, тождественная связи самой с собой. В этой аксиоме смысл пока ещё никак не дифференцируется. Основа различия — это различие смысла.

**Остенсивное определение:**

```
 /---\
|    |
 \-->*+--\
     |   |
     \---/
```

`∞` — нульарный оператор, иконически отражающий бесконечную самоссылку: начало и конец замкнуты сами на себя.

Развёртка рекурсии: `∞ = ∞ ⟼ ∞ = ∞ ⟼ ∞ ⟼ ∞ ⟼ ...`

**Смысл:**
1. **Ключевой принцип:** `∞` определяется как связь, связанная сама с собой: `∞ = ∞ ⟼ ∞`. Смысл — это не внешнее свойство, а сама структура самозамкнутой связи. Никакая другая связь не обладает этим свойством. `∞` — онтологический якорь, из которого строятся все остальные связи.
2. **Особенности структуры:**
   - Самотождественность: `∞ = ∞ ⟼ ∞` — смысл есть связь смыслов.
   - Уникальность: если `x = x ⟼ x`, то `x = ∞`.
   - Символ `∞` иконически отражает бесконечную самоссылку смысла.
   - Идемпотентность: `∞ⁿ = ∞` для любого n.
   - Самодуальность: `¬∞ = ∞`.
3. **Ограничения:**
   - `∞` не является абитом и не входит в ачисла.
   - Других полностью самозамкнутых связей не существует.

**Следствия:**
- `∞` — единственная константа системы, онтологический якорь.
- Все конструкции МТС строятся от `∞`.
- Из `∞` возникают четыре базовые формы: `∞♀`, `♂∞`, `1`, `0`.
- Рекурсивные определения имеют `∞` как базовый случай.

**Итог:** `∞` есть смысл, смысл есть связь смыслов — это форма полного самозамыкания связи, онтологический якорь и точка отсчёта всех связей в МТС.

### А5. Аксиома начала смысла

**Формально-математическое определение:**

```
∞♀ : [⟼]♀
```

**Содержательно-онтологическое определение:**

Начало смысла определяется началом связи. Аксиома вычленяет из неразличимого смысла `∞` его начало `∞♀`. Начало смысла `∞♀` — это результат применения оператора начала `♀` к связи `[⟼]`, то есть начало связи как таковой.

**Остенсивное определение:**

```
♀ — стрелка с концом, замкнутым на её собственное тело (петля сверху)

     /---\
∞+---*   |
     ^   |
     \___/

∞♀ = ∞ ⟼ ∞♀
```

**Смысл:**
1. **Ключевой принцип:** Начало смысла `∞♀` вычленяется из неразличимого смысла `∞`. Оператор `♀` извлекает начало связи:
   - `(ab)♀ = a` — применение `♀` к связи `ab` возвращает её начало `a`.
   - Конец связи определяется через бесконечность (без-конечность): чтобы быть началом, связь должна замкнуть свой конец на саму себя, освобождая начало как единственный внешний компонент.
   - Формула `∞♀ : [⟼]♀` устанавливает, что начало смысла есть начало связи — это часть самозамкнутой системы логических уравнений.
2. **Особенности структуры:**
   - `r♀` порождает рекурсивную структуру: `r♀ = r ⟼ (r♀)`.
   - Является унарным левоассоциативным оператором: `r♀♀ = (r♀)♀`.
   - Символ `♀` иконически отражает замкнутость конца (петля сверху).
   - Развёртка рекурсии: `... ⟼ (∞ ⟼ (∞ ⟼ (∞ ⟼ ∞♀)))...` — безначальная последовательность, уходящая влево.
3. **Ограничения:**
   - `♀` применяется только к связям.

**Следствия:**
- `∞♀ = ∞ ⟼ ∞♀` — конкретная бесконечная (без-конечная) связь относительно акорня.
- Связь `∞♀` занимает позицию начала в единице смысла: `(⟼) : ∞♀ ⟼ ♂∞` (А7).
- Определение абита `[`: `[ : ∞♀` (А15) — знак сериализации для начала смысла.

**Итог:** Аксиома начала смысла вычленяет из неразличимого смысла `∞` его начало `∞♀`, определяя его через начало связи `[⟼]♀`. Оператор `♀` конструирует бесконечную (без-конечную) связь, извлекая начало.

---

### А6. Аксиома конца смысла

**Формально-математическое определение:**

```
♂∞ : ♂[⟼]
```

**Содержательно-онтологическое определение:**

Конец смысла определяется концом связи. Аксиома вычленяет из неразличимого смысла `∞` его конец `♂∞`. Конец смысла `♂∞` — это результат применения оператора конца `♂` к связи `[⟼]`, то есть конец связи как таковой.

**Остенсивное определение:**

```
♂ — стрелка с началом, замкнутым на её собственное тело (петля снизу)

 /---*--->∞
|    +
 \___/

♂∞ = ♂∞ ⟼ ∞
```

**Смысл:**
1. **Ключевой принцип:** Конец смысла `♂∞` вычленяется из неразличимого смысла `∞`. Оператор `♂` извлекает конец связи:
   - `♂(ab) = b` — применение `♂` к связи `ab` возвращает её конец `b`.
   - Начало связи определяется через безначальность: чтобы быть концом, связь должна замкнуть своё начало на саму себя, освобождая конец как единственный внешний компонент.
   - Формула `♂∞ : ♂[⟼]` устанавливает, что конец смысла есть конец связи — это часть самозамкнутой системы логических уравнений.
2. **Особенности структуры:**
   - `♂v` порождает рекурсивную структуру: `♂v = (♂v) ⟼ v`.
   - Является унарным правоассоциативным оператором: `♂♂v = ♂(♂v)`.
   - Символ `♂` иконически отражает замкнутость начала (петля снизу).
   - Развёртка рекурсии: `♂∞ ⟼ ∞ ⟼ ∞ ⟼ ∞ ⟼ ...` — бесконечная последовательность, уходящая вправо.
3. **Ограничения:**
   - `♂` применяется только к связям.

**Следствия:**
- `♂∞ = ♂∞ ⟼ ∞` — конкретная безначальная связь относительно акорня.
- Связь `♂∞` занимает позицию конца в единице смысла: `(⟼) : ∞♀ ⟼ ♂∞` (А7).
- Определение абита `]`: `] : ♂∞` (А15) — знак сериализации для конца смысла.

**Итог:** Аксиома конца смысла вычленяет из неразличимого смысла `∞` его конец `♂∞`, определяя его через конец связи `♂[⟼]`. Оператор `♂` конструирует безначальную связь, извлекая конец.

### А7. Аксиома связи (единица смысла)

**Формально-математическое определение:**

```
⟼ : ∞♀ ⟼ ♂∞
```

**Содержательно-онтологическое определение:**

Связь определяется началом смысла связанным с концом смысла. Символ `⟼` определяется через `∞♀ ⟼ ♂∞` — это полностью развёрнутая структура смысла `∞`, в которой начало `∞♀` и конец `♂∞` вытянуты из полностью самозамкнутой связи. Это одновременно и само понятие связи, и единица смысла.

**Остенсивное определение:**

```
⟼ — стрелка, соединяющая ∞♀ и ♂∞

∞♀ ——⟼ ♂∞  =  (⟼)  =  1
```

**Смысл:**
1. **Ключевой принцип:** Символ `⟼` определяется формой `∞♀ ⟼ ♂∞` — это одновременно и само понятие связи (от начала к концу), и единица смысла. `(⟼)` — направленная связь от самозамкнутого начала к самозамкнутому концу. В `(⟼)` начало и конец различены максимально. Эта аксиома вытаскивает из полностью самозамкнутой связи `∞` её начало и конец.
2. **Особенности структуры:**
   - `(⟼)` соединяет два полуоткрытых полюса акорня.
   - Является основой для кодирования истинностных значений (наличие, утверждение).
   - В домене форм связей `(⟼)` — формульная константа единицы смысла.
   - Связь — это полностью развёрнутая структура смысла.
3. **Ограничения:**
   - `(⟼)` — производная константа, определяемая через `∞♀` и `♂∞`.

**Следствия:**
- `(⟼)` — основа 4-значной «алогики» вместе с `(↛)`, `∞♀` и `♂∞`.
- Совпадение формы `(⟼)` и абита `1` не случайно: абит `1` является сериализованным представлением фундаментального понятия связи.

**Итог:** Связь — минимальная структура с полным различением начала и конца. Символ `⟼` определяется через `∞♀ ⟼ ♂∞`, являясь полностью развёрнутой структурой смысла.

### А8. Аксиома единицы смысла

**Формально-математическое определение:**

```
1 : [⟼]
```

**Содержательно-онтологическое определение:**

Единица смысла определяется связью. Абит `1` вводится как сериализованное представление понятия связи `(⟼)`. Связь в квадратных скобках `[⟼]` обозначает связь как объект домена сериализации.

**Остенсивное определение:**

```
1 = [⟼] = ∞♀ ⟼ ♂∞  — абит единицы смысла (связь)
```

**Смысл:**
1. **Ключевой принцип:** Абит `1` — сериализованное представление фундаментального понятия связи. Запись `1 : [⟼]` вводит абит `1` через связь в домене сериализации.
2. **Особенности структуры:**
   - В домене сериализации `1` — абит наличия связи.
   - `1` и `(⟼)` определяются одной и той же формой `∞♀ ⟼ ♂∞`, но в разных доменах.
3. **Ограничения:**
   - `1` — абит, элемент домена сериализации.

**Следствия:**
- Используется как абит для сериализации связей в ачислах.

**Итог:** Единица смысла — абит, сериализующий понятие связи.

### А9. Аксиома несвязи

**Формально-математическое определение:**

```
↛ : ¬[⟼]
```

**Содержательно-онтологическое определение:**

Несвязь определяется инверсией связи. Символ `↛` (т.е. `¬⟼`) вводится как инверсия понятия связи `(⟼)`. Инверсия связи — это обращение направления: от конца смысла к началу смысла.

**Остенсивное определение:**

```
↛ = ¬[⟼] = ¬(∞♀ ⟼ ♂∞) = ♂∞ ⟼ ∞♀

Направление обратно связи: от конца смысла к началу смысла.
```

**Смысл:**
1. **Ключевой принцип:** Символ `↛` определяется как `¬[⟼]`, т.е. инверсия связи. Несвязь — это связь от конца смысла (`♂∞`) к началу смысла (`∞♀`). Это обратный ход от конца к началу.
2. **Особенности структуры:**
   - `¬(∞♀ ⟼ ♂∞) = ♂∞ ⟼ ∞♀`.
   - `¬(↛) = (⟼)` — двойная инверсия возвращает к связи.
   - В домене форм связей `(↛)` — формульная константа несвязи.
3. **Ограничения:**
   - `(↛)` — производная константа, определяемая через инверсию `(⟼)`.

**Следствия:**
- Пара `(⟼)`/`(↛)` образует дуальность наличия/отсутствия связи.

**Итог:** Несвязь — инверсия связи, обращение направления от конца к началу.

### А10. Аксиома нуля смысла

0 : [↛]

**Остенсивное определение:**

```
0 = [↛] = ♂∞ ⟼ ∞♀  — абит нуля смысла (несвязь)

   - В домене сериализации `0` — абит отсутствия связи.

**Следствия:**

### А11. Аксиома начала связи

**Формально-математическое определение:**

```
[⟼]♀ : [⟼] ⟼ [⟼]♀
```

**Содержательно-онтологическое определение:**

Начало связи определяется связью связанной с началом связи. Оператор `♀` применяется к связи `[⟼]`, порождая бесконечную (без-конечную) структуру. Начало связи `[⟼]♀` — это связь, конец которой замкнут сам на себя.

**Остенсивное определение:**

```
[⟼]♀ = [⟼] ⟼ [⟼]♀ = [⟼] ⟼ [⟼] ⟼ [⟼]♀ = ...

Бесконечная последовательность связей, уходящая влево.
```

**Смысл:**
1. **Ключевой принцип:** Начало связи `[⟼]♀` — это самозамыкание конца связи. Формула `[⟼]♀ : [⟼] ⟼ [⟼]♀` определяет связь, которая связана сама с собой через конец, порождая рекурсивную структуру.
2. **Особенности структуры:**
   - Рекурсивная развёртка: `[⟼]♀ = [⟼] ⟼ ([⟼] ⟼ ([⟼] ⟼ ...))`.
   - Связана с аксиомой начала смысла (А5): `∞♀ : [⟼]♀`.

**Следствия:**
- Начало связи порождает бесконечную структуру самоповторения связи.

**Итог:** Начало связи — самозамыкание конца связи, порождающее бесконечную рекурсивную структуру.

### А12. Аксиома конца связи

**Формально-математическое определение:**

```
♂[⟼] : ♂[⟼] ⟼ [⟼]
```

**Содержательно-онтологическое определение:**

Конец связи определяется концом связи связанным со связью. Оператор `♂` применяется к связи `[⟼]`, порождая безначальную структуру. Конец связи `♂[⟼]` — это связь, начало которой замкнуто само на себя.

♂[⟼] = ♂[⟼] ⟼ [⟼] = ♂[⟼] ⟼ [⟼] ⟼ [⟼] = ...

Бесконечная последовательность связей, уходящая вправо.
```

**Смысл:**
1. **Ключевой принцип:** Конец связи `♂[⟼]` — это самозамыкание начала связи. Формула `♂[⟼] : ♂[⟼] ⟼ [⟼]` определяет связь, которая связана сама с собой через начало, порождая рекурсивную структуру.
2. **Особенности структуры:**
   - Рекурсивная развёртка: `♂[⟼] = (... ⟼ ([⟼] ⟼ ([⟼] ⟼ ♂[⟼])))`.
   - Связана с аксиомой конца смысла (А6): `♂∞ : ♂[⟼]`.

**Следствия:**
- Конец связи порождает безначальную структуру самоповторения связи.

**Итог:** Конец связи — самозамыкание начала связи, порождающее безначальную рекурсивную структуру.

### А13. Аксиома инверсии связи

**Формально-математическое определение:**

```
¬[⟼] : ♂[⟼] ⟼ [⟼]♀
```

**Содержательно-онтологическое определение:**

Инверсия связи определяется концом связи связанным с началом связи. Инверсия связи `¬[⟼]` — это направленная связь от конца связи `♂[⟼]` к началу связи `[⟼]♀`.

**Остенсивное определение:**

```
¬[⟼] = ♂[⟼] ⟼ [⟼]♀

Направление обратно связи: от конца связи к началу связи.
```

**Смысл:**
1. **Ключевой принцип:** Инверсия связи `¬[⟼]` — обращение направления связи. Если связь `(⟼) = ∞♀ ⟼ ♂∞` идёт от начала к концу, то её инверсия `¬[⟼] = ♂[⟼] ⟼ [⟼]♀` идёт от конца связи к началу связи.
2. **Особенности структуры:**
   - Связана с аксиомой несвязи (А9): `↛ : ¬[⟼]`.
   - Инверсия связи раскрывает внутреннюю структуру несвязи.

**Следствия:**
- Определяет структуру несвязи через операторы начала и конца.
- `¬[⟼] = ♂[⟼] ⟼ [⟼]♀` = `(↛)`.

**Итог:** Инверсия связи — обращение направления, определяемое как связь от конца связи к началу связи.

### А14. Аксиома инверсии

**Формально-математическое определение:**

```
¬(a ⟼ b) = b ⟼ a
¬(♂v) = v♀
¬(r♀) = ♂r
¬∞ = ∞
¬¬x = x
```

**Содержательно-онтологическое определение:**

Оператор `¬` инвертирует направленность связи, меняя местами начало и конец и тем самым определяя обратный смысл связи. Инверсия — это не отрицание существования, а переконфигурация структуры.

**Остенсивное определение:**

```
¬ — стрелка, разворачивающая направление связи на противоположное

a ——⟼ b   →   ¬(a ⟼ b)   →   b ——⟼ a
```

**Смысл:**
1. **Ключевой принцип:** Оператор `¬` инвертирует направление связи. Если связь идёт от `a` к `b`, то её инверсия идёт от `b` к `a`. Инверсия устанавливает дуальность между операторами замыкания:
   - `¬(♂v) = v♀` — инверсия безначальной связи даёт бесконечную связь.
   - `¬(r♀) = ♂r` — инверсия бесконечной связи даёт безначальную связь.
   - `¬∞ = ∞` — инверсия акорня даёт акорень (самодуальность).
2. **Особенности структуры:**
   - Инволюция: `¬¬x = x` — двойная инверсия возвращает к исходному.
   - Символ `¬` обозначает смену направления связи.
   - Инверсия применима к любой связи.
3. **Ограничения:**
   - Из `a ⟼ b` и `b ⟼ c` не следует `a ⟼ c` (запрет транзитивности).

**Следствия:**
- Двойная инверсия возвращает к исходному: `¬(¬(a ⟼ b)) = a ⟼ b`.
- Инверсия распределяется по последовательности: `¬(a ⟼ b ⟼ c) = c ⟼ b ⟼ a`.
- Определение инверсии через операторы: `¬(ab) = ♂(ab) ⟼ (ab)♀`, то есть `b ⟼ a`.
- Нотация `¬⟼` (в aprover: `!->`) — синтаксический сахар для отрицания стрелки: `a ¬⟼ b = ¬(a ⟼ b)`.

**Итог:** Инверсия — операция обращения направления, обеспечивающая структурную дуальность МТС.

### А15. Аксиома абитов

**Формально-математическое определение:**

```
[ : ∞♀
] : ♂∞
```

**Содержательно-онтологическое определение:**

Два абита `[` и `]` — **абиты** (ассоциативные биты) начала и конца смысла — определяют базовые элементы сериализации. Каждый абит вводит новый знак домена сериализации для соответствующей формы связи вокруг акорня `∞`.

**Остенсивное определение:**

```
[  = ∞♀         — начало смысла (самозамкнутое начало акорня)
]  = ♂∞         — конец смысла (самозамкнутый конец акорня)
1  = ∞♀ ⟼ ♂∞   — единица смысла (от начала к концу) (А8)
0  = ♂∞ ⟼ ∞♀   — нуль смысла (от конца к началу) (А10)
[] = ∞          — акорень (комбинация начала и конца)
```

**Смысл:**
1. **Ключевой принцип:** Абиты — четыре базовые формы связей вокруг акорня, формирующие элементарные «строительные блоки» ассоциативной памяти:
   - `[` — начало смысла (`∞♀`): самозамкнутое начало акорня
   - `]` — конец смысла (`♂∞`): самозамкнутый конец акорня
   - `1` — единица смысла (`∞♀ ⟼ ♂∞`): направленная связь от начала к концу (А8)
   - `0` — нуль смысла (`♂∞ ⟼ ∞♀`): инверсия единицы (А10)
2. **Особенности структуры:**
   - Ровно четыре абита — четверичная система.
   - Каждый абит — конкретная связь вокруг акорня `∞`.
   - Записи `[ : ∞♀` и `] : ♂∞` используют `:` (определение), потому что вводят **новые символы** `[` и `]` для домена сериализации.
   - Абиты `1` и `0` вводятся отдельно аксиомами А8 и А10.
3. **Ограничения:**
   - `∞` не является абитом — это метатеоретический конструкт, выражаемый через комбинацию абитов: `[] = ∞`.

**Следствия:**
- Любая связь может быть сериализована в последовательность абитов (ачисло).

**Итог:** Абиты — мост между доменом форм связей и доменом сериализации. Абиты `[` и `]` вводятся как новые знаки через `:`, абиты `1` и `0` определяются аксиомами А8 и А10.

#### Уточнение: связь между `(⟼)`/`(↛)` и абитами `1`/`0`

Аксиомы единицы и нуля смысла (А8, А10) и аксиомы абитов (А15) задают **одни и те же формы связей**, но в **разных доменах**:

| Домен форм (формульная нотация) | Домен сериализации (абиты) | Форма связи |
|---------------------------------|----------------------------|-------------|
| `(⟼)` — единица смысла (связь) (А7) | `1` — абит наличия связи (А8) | `∞♀ ⟼ ♂∞` (от начала к концу) |
| `(↛)` — несвязь (А9) | `0` — абит отсутствия связи (А10) | `♂∞ ⟼ ∞♀` (от конца к началу) |

Таким образом:
- **`(⟼)` и `1`** — оба определяются формой `∞♀ ⟼ ♂∞`, но `(⟼)` — это формульная константа, а `1` — абит для сериализации
- **`(↛)` и `0`** — оба определяются формой `♂∞ ⟼ ∞♀`, но `(↛)` — это формульная константа, а `0` — абит для сериализации

Совпадение форм не случайно: абиты `1` и `0` являются **сериализованными представлениями** фундаментальных понятий связи и несвязи.

### А16. Аксиома левоассоциативности

**Формально-математическое определение:**

```
abc = (a ⟼ b) ⟼ c
a(bc) ≠ (a ⟼ b) ⟼ c
```

**Содержательно-онтологическое определение:**

Последовательность связей группируется слева направо. Правоассоциативная группировка даёт нетождественный результат. Это онтологический принцип построения сложных структур из простых.

**Остенсивное определение:**

```
abc = ((a ⟼ b) ⟼ c) — сначала связываются a и b, затем результат с c

a ⟼ b ⟼ c  =  ((a ⟼ b) ⟼ c)  ≠  (a ⟼ (b ⟼ c))
```

**Смысл:**
1. **Ключевой принцип:** При записи последовательности `abc` группировка производится слева направо: сначала связываются `a` и `b`, затем результат связывается с `c`. Это онтологический принцип построения сложных структур из простых — каждая новая связь присоединяется к результату предыдущего акта связывания.
2. **Особенности структуры:**
   - Последовательность: обработка слева направо.
   - Группировка: каждая пара связывается перед добавлением следующего элемента.
   - `a(bc) ≠ abc` — правоассоциативная группировка явно нетождественна левоассоциативной.
3. **Ограничения:**
   - Правоассоциативная группировка не допускается без явного указания скобками.

**Следствия:**
- Предсказуемый порядок построения структур: `abcd = ((a ⟼ b) ⟼ c) ⟼ d`.
- Основа для алгоритмов сериализации и десериализации.

**Итог:** Левоассоциативность — принцип последовательного построения сложности из простоты.

### А17. Аксиома контекста (квадратные скобки)

**Формально-математическое определение:**

```
[x] : ∞♀ ⟼ x ⟼ ♂∞
```

**Содержательно-онтологическое определение:**

Контекст определяется началом смысла связанным с содержимым контекста связанным с концом смысла. Квадратные скобки `[` и `]` образуют оператор контекста `[...]`, который помещает формулу `x` домена форм связей в контекст сериализации, создавая ачисло.

**Остенсивное определение:**

```
[x] = ∞♀ ⟼ x ⟼ ♂∞ = [ ⟼ x ⟼ ]

Примеры:
  [⟼] = ∞♀ ⟼ (⟼) ⟼ ♂∞ = [ ⟼ 1 ⟼ ] = [1] — ачисло единицы смысла
  [↛] = ∞♀ ⟼ (↛) ⟼ ♂∞ = [ ⟼ 0 ⟼ ] = [0] — ачисло нуля смысла
  []  = ∞♀ ⟼ ♂∞ = ∞     — пустой контекст равен акорню (А4)
```

**Смысл:**
1. **Ключевой принцип:** Квадратные скобки — это **междоменный мост** между доменом форм связей и доменом сериализации. Запись `[x]` означает помещение формы `x` в контекст, ограниченный началом смысла `∞♀` (= `[`) и концом смысла `♂∞` (= `]`). Результат — ачисло, представляющее форму `x` в домене сериализации.
   - Запись `[⟼]` одновременно является формулой (скобки вокруг оператора связи) и ачислом `[1]` (последовательность абитов `[`, `1`, `]`).
   - Это совпадение не случайно: формальная нотация и ачисла пересекаются в точке междоменного моста.
2. **Особенности структуры:**
   - Пустой контекст `[]` равен акорню `∞`: `[] = ∞♀ ⟼ ♂∞ = (⟼) = ∞` (следствие из А4, А7, А15).
   - Контекст сохраняет структуру содержимого: `[a ⟼ b] = ∞♀ ⟼ a ⟼ b ⟼ ♂∞`.
   - Вложенные контексты допускаются: `[[x]] = [∞♀ ⟼ x ⟼ ♂∞]`.
   - Связан с А15 (абиты): `[` и `]` — те же абиты начала и конца смысла.
3. **Ограничения:**
   - Контекст `[...]` принадлежит формальной нотации как конструктор домена сериализации.

**Следствия:**
- Каждая форма связи может быть помещена в контекст сериализации через `[...]`.
- Аксиомы А8 (`1 : [⟼]`) и А10 (`0 : [↛]`) являются частными случаями применения контекста.
- Двойственная природа `[⟼]` — одновременно формула и ачисло — объясняет глубокое пересечение доменов.

**Итог:** Аксиома контекста формализует квадратные скобки как междоменный мост, превращающий формы связей в ачисла. Запись `[⟼]` — точка пересечения формальной нотации и домена сериализации.

## Ачисла (ассоциативные числа)

**Ачисло** — это конечная последовательность абитов, являющаяся уникальным идентификатором связи, который можно использовать как ссылку на связь.

### Формы представления

```
Полная форма:    ачисло = абит₁ абит₂ ... абитₙ
Строковая форма: ачисло = "абит₁абит₂...абитₙ"
Четверичная:     ачисло = (q₁, q₂, ..., qₙ), где qᵢ ∈ {0, 1, 2, 3}
```

### Операции

**Конкатенация:** `ачисло₁ ⊕ ачисло₂ = абит₁...абитₘ абит₁'...абитₙ'`

**Инверсия:** `¬(ачисло) = ¬(абит₁...абитₙ) = (¬абит₁)...(¬абитₙ)`

**Длина:** `|ачисло| = количество абитов`

## Теоремы

### Теорема 1. Конец начала (слияние рекурсий)

```
♂♀ = ∞
```

Посимвольное прочтение: конец начала равен смыслу.

**Доказательство:**
1. По аксиоме А6 (конец смысла) и А12 (конец связи): `♂♀ = (♂♀) ⟼ ♀`.
2. По аксиоме А5 (начало смысла) и А11 (начало связи): `♂♀ = ♂ ⟼ (♂♀)`.
3. Из (1) и (2): начало `♂♀` равно `♂♀`, конец `♂♀` равен `♂♀`.
4. Следовательно: `♂♀ = (♂♀) ⟼ (♂♀)`.
5. По аксиоме А4 и А2: связь формы `x = x ⟼ x` единственна и есть `∞`.
6. Поэтому: `♂♀ = ∞`.

**Смысл:** Полное слияние рекурсий по началу и концу порождает акорень. Конец начала замыкается в смысл.

---

### Теорема 2. Двойная инверсия

```
¬(¬(a ⟼ b)) = a ⟼ b
```

**Доказательство:**
1. По аксиоме А14: `¬(a ⟼ b) = b ⟼ a`.
2. Применяя инверсию повторно: `¬(b ⟼ a) = a ⟼ b`.
3. Следовательно: `¬(¬(a ⟼ b)) = a ⟼ b`.

**Смысл:** Двойная инверсия направления возвращает к исходной связи — принцип обратимости.

---

### Петля

```
aa : a ⟼ a
```

Петля — это связь, начало и конец которой равны одной и той же связи `a`. Петля отличается от полного самозамыкания (А4): в петле `a ⟼ a` связь `a` указывает сама на себя, но `a` не обязательно равна `a ⟼ a`. Если `a = a ⟼ a`, то по А4 следует `a = ∞`.

Степень петли: `a² = aa = a ⟼ a`, `a³ = aaa = (a ⟼ a) ⟼ a`.

---

### Теорема 3. Развёртка начала смысла

```
∞♀ = ∞ ⟼ ∞♀
```

**Доказательство:**
1. По аксиоме А5 (начало смысла): `∞♀ : [⟼]♀`.
2. По аксиоме А11 (начало связи): `[⟼]♀ : [⟼] ⟼ [⟼]♀`.
3. По аксиоме А7 (связь): `(⟼) : ∞♀ ⟼ ♂∞`, т.е. `[⟼] = ∞♀ ⟼ ♂∞`.
4. Начало `[⟼]` равно `∞♀`, а `∞♀ = [⟼]♀` (А5).
5. Подставляя `∞` как начало: `∞♀ = ∞ ⟼ ∞♀`.

**Смысл:** Начало смысла `∞♀` — это конкретная бесконечная (без-конечная) связь. Начало `∞♀` — акорень `∞`, а его конец замкнут сам на себя. Связь `∞♀` занимает позицию начала в единице смысла: `(⟼) : ∞♀ ⟼ ♂∞` (А7).

---

### Теорема 4. Развёртка конца смысла

```
♂∞ = ♂∞ ⟼ ∞
```

**Доказательство:**
1. По аксиоме А6 (конец смысла): `♂∞ : ♂[⟼]`.
2. По аксиоме А12 (конец связи): `♂[⟼] : ♂[⟼] ⟼ [⟼]`.
3. По аксиоме А7 (связь): `(⟼) : ∞♀ ⟼ ♂∞`, т.е. `[⟼] = ∞♀ ⟼ ♂∞`.
4. Конец `[⟼]` равен `♂∞`, а `♂∞ = ♂[⟼]` (А6).
5. Подставляя `∞` как конец: `♂∞ = ♂∞ ⟼ ∞`.

**Смысл:** Конец смысла `♂∞` — это конкретная безначальная связь. Его начало замкнуто само на себя, а конец — акорень `∞`. Связь `♂∞` занимает позицию конца в единице смысла: `(⟼) : ∞♀ ⟼ ♂∞` (А7).

---

### Соотношение аксиом самозамкнутой системы

Аксиомы А4–А7 образуют **самозамкнутую систему логических уравнений**, в которой каждое понятие определяется через другие:

| Аксиома | Формула | Что вводит | Через что определяется |
|---------|---------|------------|----------------------|
| А4. Смысл | `∞ : ∞ ⟼ ∞` | `∞` | сам себя |
| А5. Начало смысла | `∞♀ : [⟼]♀` | `∞♀` | `♀` и `[⟼]` |
| А6. Конец смысла | `♂∞ : ♂[⟼]` | `♂∞` | `♂` и `[⟼]` |
| А7. Связь | `⟼ : ∞♀ ⟼ ♂∞` | `⟼` | `∞♀` и `♂∞` |

Система не решается по частям — все четыре аксиомы взаимозависимы и обретают смысл только в совокупности. Это принцип самозамкнутости аксиоматики МТС.

В аксиоме А15 (абиты) знаки `[ : ∞♀` и `] : ♂∞` корректно используют `:`, потому что вводят **новые символы** `[` и `]` для домена сериализации.

Аксиома А17 (контекст) формализует квадратные скобки `[...]` как междоменный мост: `[x] : ∞♀ ⟼ x ⟼ ♂∞`. Это объясняет, почему `[⟼]` одновременно является формулой (связь в скобках) и ачислом `[1]` — запись `[⟼]` принадлежит обоим доменам.

## Междоменные интерфейсы

### Преобразование форм связей в абиты

```
∞♀       → [
♂∞       → ]
∞♀ ⟼ ♂∞ → 1
♂∞ ⟼ ∞♀ → 0
```

### Разложение последовательности связей

Любая последовательность связей может быть разложена на элементарные связи и сериализована в ачисло. Левоассоциативность (А16) обеспечивает однозначность разложения.

```
истина  = 1
ложь    = 0
¬(a)    = инверсия a
```

### Базовые числа
```
1 = 1
2 = 11
3 = 111
n = 1ⁿ (n повторений абита 1)
```

### Сериализация строк
Каждый символ кодируется ачислом, строка — последовательность ачисел символов.

## Три нотации МТС

МТС определяет три ортогональных способа записи выражений:

### 1. Формальная нотация (`.mtl`)

Язык запросов по форме связей — основной язык теории, который читает прувер.

| Символ | Описание |
|--------|----------|
| `∞` | Акорень (полное самозамыкание) |
| `♂ ...` | Конечность — самозамыкание начала (префиксный) |
| `... ♀` | Начальность — самозамыкание конца (постфиксный) |
| `a ⟼ b` | Связь от начала `a` к концу `b` (левоассоциативно) |
| `a ¬⟼ b` | Отрицание стрелки: `¬(a ⟼ b)` (синтаксический сахар) |
| `¬t` | Инверсия (унарный префикс) |
| `s : F` | Определение знака `s` формой `F` |
| `A = B` | Тождественность (структурная неразличимость) |
| `A ≠ B` | Отрицание тождества |
| `{ ... }` | Пакет (контейнер множества выражений) |

**Принцип:** Даже `(s : F)` и `(A = B)` — объекты системы, которые можно связывать через `⟼`.

### 2. Строковые ачисла (`.astr`)

UTF-8 представление: каждый символ `c` вводится формально через `'c' : T`, затем строка `c₁c₂...cₙ` интерпретируется как левоассоциативная цепочка:

```
decode(c₁...cₙ) = (((∞ ⟼ c₁) ⟼ c₂) ⟼ ... ⟼ cₙ)
```

### 3. Четверичная (абитовая) нотация (`.anum`)

Алфавит ровно из 4 символов: `[`, `]`, `1`, `0` (унифицировано с aprover).

Допускаются вложенные контексты: `[ ... ]`.

Результат абитового парсинга конвертируется в формальные термы через определения абитов (А15).

## EBNF формальной нотации

Лексические соглашения: пробелы/переводы строк — разделители; комментарии от `//` до конца строки.

```ebnf
File      ::= { Stmt } ;
Stmt      ::= Expr [ "," ] ;
Expr      ::= DefExpr | EqExpr | NeqExpr | Term ;
DefExpr   ::= Term ":" Term ;
EqExpr    ::= Term "=" Term ;
NeqExpr   ::= Term ("≠" | "¬=") Term ;
Term      ::= Chain ;
Chain     ::= Pref { ("⟼" | "¬⟼") Pref } ;
Pref      ::= { "¬" | "♂" } Post ;
Post      ::= Atom { "♀" | Pow } ;
Pow       ::= "^" Nat ;
Atom      ::= Const | Id | AbitLit | StringLit | Set | "(" Expr ")" ;
Set       ::= "{" Expr { "," Expr } "}" ;
Const     ::= "∞" | "1" | "0" ;
AbitLit   ::= "'" { AbitChar } "'" ;
AbitChar  ::= "[" | "]" | "1" | "0" ;
StringLit ::= '"' { Utf8Char } '"' ;
Id        ::= Letter { Letter | Digit | "_" } ;
Nat       ::= Digit { Digit } ;
```

**Примечание:** EBNF приведён в нотации anum_docs. В aprover используется ASCII-синтаксис `->`, `!->`, `!` для формальных операторов — см. таблицу соответствия. Символы абитов `[`, `]`, `1`, `0` унифицированы.

## Ядро прувера

### Правило вывода

Единственный фундаментальный шаг вывода — **Modus Ponens (MP)**:

> Если доказано `P` и существует выражение `(P ⟼ Q)`, то доказано `Q`.

Вся логика (равенство, симметрия, транзитивность, конгруэнция, свойства `:`) задаётся не встроенными правилами, а аксиомами, которые создают нужные связи `P ⟼ Q`.

### Нормализация

- `¬⟼`: синтаксический сахар — `a ¬⟼ b` нормализуется в `¬(a ⟼ b)`.
- Степени `^n`: синтаксический сахар — `a^1 = a`, `a^(n+1) = (aⁿ ⟼ a)`.

### Ограждённая рекурсия

Для определений `(s : F)`: рекурсивное упоминание `s` в `F` разрешено только под конструктором `⟼`.

## Заключение

Метатеория связей представляет собой онтологически замкнутую формальную систему из 17 аксиом (А0–А16), в которой всё бытие выражается через направленные связи. Ядро системы (А4–А7) образует самозамкнутую систему логических уравнений, в которой каждое понятие определяется через другие и система обретает смысл только в совокупности. Разделение на домен форм связей и домен сериализации обеспечивает как теоретическую строгость, так и практическую применимость.

Система МТС является:
- **Минималистичной** — основана на едином операторе `⟼` и 17 аксиомах
- **Универсальной** — выражает логику, числа, типы, данные
- **Вычислимой** — пригодна для реализации в ассоциативной памяти
- **Иконичной** — символы отражают структуру связей
- **Онтологически замкнутой** — все конструкции выражаются через связи
