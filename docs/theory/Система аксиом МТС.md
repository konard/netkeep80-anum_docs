# Система аксиом МТС

Статус: актуальное, нормативное.

Каждая аксиома имеет формулу формальной нотации МТС. Система формул аксиом решается одновременно и образует корневую библиотеку апрувера.

## A1. Акорень

Формула:

```text
∞ : [] = [] ⟼ []
[] = ∞
∞ = ∞ ⟼ ∞
```

Чтение:

```text
[] — минимальная завершённая форма одной связи
∞ — акорень
акорень несёт смысл смысла
```

связь — единственная форма существования, поэтому акорень является связью полного самозамыкания.

## A2. Пустая круглая форма смысла

Формула:

```text
() : ♀() ⟼ ()♂
```

Чтение:

```text
() — минимальная формальная форма смысла
♀() — начало формальной формы смысла
()♂ — конец формальной формы смысла
```

Смысл не существует отдельно от связи: связь и есть смысл в своей различённой форме.

## A3. Смыслы квадратных абитов

Формулы:

```text
([) : (♀∞)
(]) : (∞♂)
```

Чтение:

```text
([) — смысл левого квадратного абита
(]) — смысл правого квадратного абита
```

В `([)` и `(])` квадратные скобки являются буквальными абитами внутри круглой формальной нотации.

## A4. Связь и несвязь

Формулы:

```text
(⟼) : (♀∞ ⟼ ∞♂)
(↛) : (∞♂ ⟼ ♀∞)
```

Чтение:

```text
(⟼) — смысл связи
(↛) — смысл несвязи
```

Несвязь не существует в натуре. Смысл несвязи выражается связью. Обратное направление связи не является отсутствием связи.

## A5. Квадратные формы абитов

Формулы:

```text
[1] : (⟼)
[0] : (↛)
```

Чтение:

```text
[1] — квадратная форма абита связи
[0] — квадратная форма абита несвязи
0 — абит связи, несущей смысл несвязи
```

Абит 0 не является отсутствием связи в натуре.

## A6. Равенство

Формула:

```text
(=) : {[]♀ = []♀, ♂[] = ♂[]}
```

Чтение:

Равенство фиксирует совпадение форм связей. Равенство не является простой идентичностью определения. Формы связей являются видами самозамыканий. Рекурсивная процедура сравнения различает формы рекурсий. Равенство не требует бесконечного раскрытия рекурсивных связей.

Повторные `[]` в формуле равенства являются позиционными формами, сравниваемыми по смыслу, то есть по форме самозамыкания.

## Сводный блок

```text
∞ : [] = [] ⟼ []
[] = ∞
∞ = ∞ ⟼ ∞

() : ♀() ⟼ ()♂

([) : (♀∞)
(]) : (∞♂)

(⟼) : (♀∞ ⟼ ∞♂)
(↛) : (∞♂ ⟼ ♀∞)

[1] : (⟼)
[0] : (↛)

(=) : {[]♀ = []♀, ♂[] = ♂[]}
```
