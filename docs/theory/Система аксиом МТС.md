# Система аксиом МТС

Статус: рабочее.

Документ фиксирует формулы, которые согласованы с нормативным шаблоном аксиомы и отражены в `tests/mtc_formulas.mtc`.

## Служебная рамка

Перед чтением аксиом действуют правила формальной нотации.

```text
{} — шаблонный поиск без фильтра / связь-кандидат шаблона
```

```text
Внутри одного исполнения шаблона все одинаковые вхождения `{}` относятся к одной и той же связи-кандидату.
```

```text
В последовательностной записи `{}{}...` каждое вхождение `{}` задаёт отдельную позицию кандидата.
```

```text
Круглые скобки не меняют смысл формы, но выделяют форму как целый операнд.
```

Круглые скобки фиксируют границу уже собранной формы: `({})`, `({}{})`, `({} ⟼ {})`.

```text
Исполнение шаблона — нахождение связи-кандидата, удовлетворяющей ограничениям формы, и связывание найденного смысла с вводимым знаком.
```

```text
: — акт введения знака для смысла, найденного по форме
= — отношение структурной неразличимости после исполнения шаблона
!= — отношение различимости форм после исполнения шаблона
```

Запрещённые чтения `{}`:

```text
{} ≠ пустое множество
{} ≠ пустой результат поиска
{} ≠ несвязь
{} ≠ 0
```

## А1. Акорень

**Вводимый символ или механизм**

`∞` — знак смысла полного самозамыкания.

**Статус и слой**

Смысл связи.

**Арность / валентность**

Нульарный знак смысла.

**Формула**

```text
∞ : {} = {} ⟼ {}
```

**Шаблонное чтение**

Найти смысл, для которого связь-кандидат тождественна связи этой же формы с самой собой.

**Правило связывания повторных шаблонов**

Три вхождения `{}` относятся к одному кандидату `X`:

```text
X = X ⟼ X
```

**После исполнения шаблона**

```text
∞ = ∞ ⟼ ∞
```

**Ограничения и запрещённые чтения**

- `∞ не является абитом`;
- `{}` не является пустым множеством;
- развёртка `∞ = ∞ ⟼ ∞` не является исходной тавтологией без шаблона.

**Открытые вопросы**

Нужно отдельно завершить собственную аксиоматизацию `:` и служебных границ `{`, `}`.

## А2. Группировка формы

**Вводимый символ или механизм**

Круглые скобки как служебная группировка формы.

**Формула**

```text
({}) = {}
```

**Как читается**

Круглые скобки не меняют смысл формы, но выделяют форму как целый операнд.
Круглые скобки фиксируют границу уже собранной формы.

**Что запрещает**

- круглые скобки не являются абитами;
- `{}{}{} != {}({}{})`.

**Открытые вопросы**

Нужно уточнить полную грамматику вложенной группировки.

## А3. Последовательность двух форм

**Вводимый символ или механизм**

Последовательная запись двух форм.

**Формула**

```text
{}{} : ({}) ⟼ {}
{}({}) : {} ⟼ ({})
{}{} : {} ⟼ {}
{}{} = {} ⟼ {}
```

**Как читается**

Последовательность двух форм есть связь первой позиционной формы со второй позиционной формой.

**Что запрещает**

- `{}{}` читается как позиционная пара `AB`, а не как `XX`;
- последовательность не является строковым ачислом сама по себе.

**Открытые вопросы**

Нужно описать исполнение последовательностей длины больше трёх.

## А4. Прямоассоциативность последовательности

**Вводимый символ или механизм**

Левая группировка последовательной записи.

**Формула**

```text
{}{}{} : ({}{}) ⟼ {}
{}{}{} = (({}) ⟼ {}) ⟼ {}
{}{}{} = {} ⟼ {} ⟼ {}
{}({}{}) : {} ⟼ ({}{})
{}{}{} != {}({}{})
{}{}{} != {} ⟼ ({} ⟼ {})
```

**Как читается**

Последовательность из трёх форм группируется слева направо.

```text
ABC = (AB) ⟼ C
AB = A ⟼ B
ABC = (A ⟼ B) ⟼ C
A(BC) = A ⟼ (B ⟼ C)
ABC != A(BC)
```

**Что запрещает**

- последовательность не является правоассоциативной по умолчанию;
- правая группировка требует явных круглых скобок.

**Открытые вопросы**

Нужно формализовать последовательности произвольной длины.

## А5. Самозамкнутое начало

**Вводимый символ или механизм**

`♂` — унарный префиксный вид формы с самозамкнутым началом.

**Формула**

```text
♂{} : ♂{} = ♂{} ⟼ {}
```

**Как читается**

Для кандидата `X` найти форму `♂X`, у которой начало удерживает эту же форму, а конец остаётся кандидатом `X`.

**После исполнения шаблона**

```text
♂∞ = ♂∞ ⟼ ∞
```

**Что запрещает**

- `♂` не является самостоятельной связью без операнда;
- `X` не является внутренним символом МТС.

**Открытые вопросы**

Нужно уточнить связь `♂` с полной формализацией извлечения конца связи.

## А6. Самозамкнутый конец

**Вводимый символ или механизм**

`♀` — унарный постфиксный вид формы с самозамкнутым концом.

**Формула**

```text
{}♀ : {}♀ = {} ⟼ {}♀
```

**Как читается**

Для кандидата `X` найти форму `X♀`, у которой конец удерживает эту же форму, а начало остаётся кандидатом `X`.

**После исполнения шаблона**

```text
∞♀ = ∞ ⟼ ∞♀
```

**Что запрещает**

- `♀` не является самостоятельной связью без операнда;
- `X` не является внутренним символом МТС.

**Открытые вопросы**

Нужно уточнить связь `♀` с полной формализацией извлечения начала связи.

## А7. Начало и конец акорня

**Формула**

```text
∞♀ : [⟼]♀
♂∞ : ♂[⟼]
```

**Какие различия вводит**

Вводятся начало акорня `∞♀` и конец акорня `♂∞` через конкретную связь `[⟼]`.

**Как читается**

`∞♀` — начало акорня, извлекаемое как начало конкретной связи `[⟼]`.
`♂∞` — конец акорня, извлекаемый как конец конкретной связи `[⟼]`.

**Что запрещает**

- начало и конец акорня не выводятся из квадратных скобок как группировки;
- `[⟼]` не является смыслом связи.

**Открытые вопросы**

Нужно завершить точную модель извлечения начала и конца произвольной связи.

## А8. Смысл связи и конкретная связь

**Формула**

```text
(⟼) : [] ⟼ []
[⟼] : ∞♀ ⟼ ♂∞
```

**Какие различия вводит**

Различаются смысл связи `(⟼)` и конкретная связь `[⟼]`.

**Как читается**

`(⟼)` — смысл связи как формы связи одной связи с другой связью.
`[⟼]` — конкретная связь как связь начала акорня с концом акорня.

**Что запрещает**

- нельзя смешивать `(⟼)` и `[⟼]`;
- `⟼` не используется как нульарное имя без указанного уровня.

**Открытые вопросы**

Нужно уточнить, как будущий исполнитель будет различать смысл конструктора и его применение.

## А9. Инверсия формы связи

**Формула**

```text
¬[] : ♂[] ⟼ []♀
¬[⟼] : ♂[⟼] ⟼ [⟼]♀
¬[⟼] : ♂∞ ⟼ ∞♀
```

**Какие различия вводит**

Вводятся инверсия формы связи и инверсия конкретной связи.

**Как читается**

Инверсия формы связи есть связь её конца с её началом.
Для конкретной связи `[⟼]` развёртка даёт `♂∞ ⟼ ∞♀`.

**Что запрещает**

- `¬` не должен неявно применяться к конкретной связи знака;
- инверсия конкретной связи не является смыслом неравенства.

**Открытые вопросы**

Нужна строгая семантика `↛` и связь `0` с сериализацией отсутствия.

## А10. Смысл равенства

**Формула**

```text
(=) : {[]♀ = []♀, ♂[] = ♂[]}
```

**Какие различия вводит**

Вводится смысл равенства через совпадение начал и концов сравниваемых форм.

**Как читается**

```text
A = B
если
A♀ = B♀
и
♂A = ♂B
```

Повторные `[]` внутри формулы равенства читаются позиционно.

**Что запрещает**

- формула не читается как тавтология одной и той же формы;
- равенство не сводится к текстовому совпадению записи.

**Открытые вопросы**

Остаются открытыми полная модель результата сравнения и тип результата `[] = []`.

## А11. Неравенство как инверсия смысла равенства

**Формула**

```text
(!=) : ¬(=)
[] != [] : ¬([] = [])
```

**Какие различия вводит**

Вводится смысл неравенства как инверсия смысла равенства и результат конкретного сравнения.

**Как читается**

`(!=)` применяется к `(=)`. Запись `[] != []` применяется к результату сравнения двух форм.

**Что запрещает**

```text
¬[=] не означает !=
```

Инверсия конкретной связи знака равенства не является смыслом неравенства.

**Открытые вопросы**

Нужно уточнить полную модель результата сравнения.

## А12. Несвязь

**Формула**

```text
↛ : ¬[⟼]
```

**Какие различия вводит**

Вводится несвязь как смысл, связанный с инверсией конкретной связи.

**Как читается**

`↛` — смысл несвязи; он не является пустым результатом поиска и не тождественен `0`.

**Что запрещает**

- `↛` не заменяет `{}`;
- `0` не вводится напрямую как инверсия связи.

**Открытые вопросы**

Нужна строгая семантика `↛`.

## А13. Абиты квадратной нотации

**Формула**

```text
[ : ∞♀
] : ♂∞
1 : [⟼]
0 : [↛]
```

**Какие различия вводит**

Вводятся абиты квадратной нотации `[`, `]`, `1`, `0`.

**Как читается**

`[` — абит начала.
`]` — абит конца.
`1` — абит конкретной связи.
`0` — абит несвязи или отсутствия связевой формы в сериализации.

**Что запрещает**

- `[` и `]` не являются формульной группировкой;
- `∞ не является абитом`;
- `0` не является пустым результатом поиска.

**Открытые вопросы**

Остаётся открытой связь `0` с сериализацией отсутствия.

## Что не входит в рабочее ядро

Не входят в рабочее ядро:

- пустой результат поиска;
- несколько независимых `{}` вне последовательностной записи;
- полная модель результата сравнения;
- строгая семантика `↛`;
- связь `0` с сериализацией отсутствия;
- будущая теория переменных и подстановки;
- объектный статус символов `{` и `}`.

Они перечислены в [`Открытые вопросы новой аксиоматики МТС`](../research/Открытые%20вопросы%20новой%20аксиоматики%20МТС.md).
