# Система аксиом МТС

Статус: рабочее.

Документ фиксирует корневую систему формул, отражённую в `tests/mtc_formulas.mtc`.

## Система аксиом как корневая библиотека апрувера

Каждая аксиома имеет формулу формальной нотации МТС. Система формул аксиом решается одновременно. Система формул аксиом составляет корневую библиотеку апрувера.

Документация ниже поясняет формулы и сопровождает их. Аксиома входит в корневую библиотеку через свою формулу.

## Служебная рамка

Перед чтением аксиом действуют три первичные скобочные нотации:

```text
(...) — явная формальная форма / группировка формы
[...] — нотация ачисла; форма одной связи
{...} — пучковая нотация; форма пучка / асети связей
```

`:` остаётся служебным введением различия через формулу. `=`, `!=`, `⟼`, `¬`, `↛` получают рабочие корневые формулы ниже, а их полная модель для будущего апрувера ведётся в слое развития.

## Единый положительный шаблон карточки

Каждая карточка R1-R15 ведётся в едином положительном шаблоне:

```text
## Rn. Имя аксиомы

Формула:
...

Вводимые различия:
...

Чтение:
...

Слои различения:
...

Связанные формулы:
...

Слой развития:
...
```

Карточка описывает текущую систему через положительные различия: какие различия вводит формула, как она читается, к каким слоям относятся её элементы, с какими формулами она связана и какие темы остаются в слое развития.

## R1. Акорень через пустую форму одной связи

Формула:

```text
∞ : [] = [] ⟼ []
[] = ∞
∞ = ∞ ⟼ ∞
```

Вводимые различия:

`∞` как полное самозамыкание и `[]` как пустую форму одной связи.

Чтение:

акорень вводится через интерпретацию пустой формы одной связи;
`[]` читается как пустая форма одной связи;
`[] = ∞` фиксирует минимальную ачисловую запись акорня;
после этой фиксации допустима развёртка `∞ = ∞ ⟼ ∞`.

Слои различения:

`[]` принадлежит квадратной нотации как пустая форма одной связи;
`∞` принадлежит слою знака полного самозамыкания;
формула `[] = ∞` принадлежит слою введения, а развёртка `∞ = ∞ ⟼ ∞` — слою следствия.

Связанные формулы:

R2 фиксирует группировку формы;
R9 вводит начало и конец акорня `∞♀` и `♂∞`.

Слой развития:

точная аксиоматизация `:` и `=`.

## R2. Круглая группировка формы

Формула:

```text
([]) = []
([][]) = [][]
([] ⟼ []) = [] ⟼ []
```

Вводимые различия:

круглые скобки как явную границу уже имеющейся формальной формы.

Чтение:

круглая группировка сохраняет интерпретацию формы;
она фиксирует форму как один операнд там, где это нужно для приоритета.

Слои различения:

`()` принадлежит формальной нотации как граница формы;
`[]` принадлежит квадратной нотации как форма одной связи;
статус пустой круглой формы относится к слою развития.

Связанные формулы:

R4 использует круглую группировку для различения левой сборки и правой группировки.

Слой развития:

статус пустой круглой формы `()`.

## R3. Последовательность двух форм

Формула:

```text
[][] : [] ⟼ []
[][] = [] ⟼ []
```

Вводимые различия:

последовательную запись двух форм как связь первой формы со второй формой.

Чтение:

две формы подряд дают форму связи `[][] = [] ⟼ []`.

Слои различения:

последовательность `[][]` принадлежит слою формальной формы;
форма одной связи `[]` принадлежит квадратной нотации;
позиционное чтение повторов относится к слою развития.

Связанные формулы:

R4 расширяет последовательность до трёх форм;
R12 использует позиционные сравниваемые формы.

Слой развития:

как будущий апрувер различает позиции последовательности и повтор внутри шаблона.

## R4. Последовательность трёх форм

Формула:

```text
[][][] : ([][]) ⟼ []
[][][] = ([] ⟼ []) ⟼ []
[][][] = [] ⟼ [] ⟼ []

[]([][]) : [] ⟼ ([][])
[][][] != []([][])
[][][] != [] ⟼ ([] ⟼ [])
```

Вводимые различия:

левую сборку последовательности по умолчанию и явную правую группировку.

Чтение:

три формы подряд собираются слева `[][][] = ([] ⟼ []) ⟼ []`;
правая группировка требует круглых скобок `[]([][]) : [] ⟼ ([][])`.

Слои различения:

левая сборка `[][][]` и правая группировка `[]([][])` принадлежат слою формальной формы;
круглые скобки принадлежат формальной нотации;
знак `!=` фиксирует результат различения форм.

Связанные формулы:

R2 вводит круглую группировку;
R3 вводит последовательность двух форм.

Слой развития:

полная индукция последовательностей произвольной длины.

## R5. Самозамкнутое начало

Формула:

```text
♂[] : ♂[] = ♂[] ⟼ []
♂∞ = ♂∞ ⟼ ∞
```

Вводимые различия:

`♂` как префиксный вид формы с самозамкнутым началом.

Чтение:

`♂[]` задаёт форму, у которой начало удерживает эту же форму, а конец остаётся формой одной связи.

Слои различения:

`♂` принадлежит слою префиксного вида формы;
абиты `[`, `]`, `1`, `0` принадлежат квадратной нотации и вводятся в R15.

Связанные формулы:

R6 вводит самозамкнутый конец `♀`;
R9 связывает `♂∞` с концом акорня.

Слой развития:

связь `♂` с будущей формализацией извлечения конца связи.

## R6. Самозамкнутый конец

Формула:

```text
[]♀ : []♀ = [] ⟼ []♀
∞♀ = ∞ ⟼ ∞♀
```

Вводимые различия:

`♀` как постфиксный вид формы с самозамкнутым концом.

Чтение:

`[]♀` задаёт форму, у которой конец удерживает эту же форму, а начало остаётся формой одной связи.

Слои различения:

`♀` принадлежит слою постфиксного вида формы;
абиты квадратной нотации вводятся отдельно в R15.

Связанные формулы:

R5 вводит самозамкнутое начало `♂`;
R9 связывает `∞♀` с началом акорня.

Слой развития:

связь `♀` с будущей формализацией извлечения начала связи.

## R7. Фигурная пучковая нотация

Формула:

```text
{} != []
{[]} != []
{[], []} = {[]}
{[], [][]} = {[][], []}
```

Вводимые различия:

фигурный контейнер как форму пучка / асети связей.

Чтение:

`{}` — пустой пучок связей;
`{[]}` — пучок из одной формы одной связи;
пучок экстенсионален: порядок элементов не важен, а повтор элемента не создаёт новый элемент.

Слои различения:

пустой пучок `{}` принадлежит пучковой нотации и отличается от пустой формы одной связи `[]`;
одноэлементный пучок `{[]}` принадлежит пучковой нотации и отличается от своего элемента;
операционное раскрытие пучка относится к R8.

Связанные формулы:

R8 вводит пучковое раскрытие.

Слой развития:

мультпучки, операции над пучками и связь с асетью.

## R8. Пучковое раскрытие

Формула:

```text
[]{[], [][]} = {[] ⟼ [], [] ⟼ [][]}
{[], [][]}[] = {[] ⟼ [], [][] ⟼ []}
{[], [][]}{[], [][]} = {[] ⟼ [], [] ⟼ [][], [][] ⟼ [], [][] ⟼ [][]}
[]{} = {}
{}[] = {}
```

Вводимые различия:

правое, левое, двустороннее и пустое раскрытие пучковой формы.

Чтение:

правое раскрытие строит пучок исходящих связей;
левое раскрытие строит пучок входящих связей;
двустороннее раскрытие строит произведение связей;
пустое раскрытие даёт пустой пучок связей.

Слои различения:

`{}` — пустой пучок;
`[]{}` — правое раскрытие по пустому пучку;
`{}[]` — левое раскрытие по пустому пучку;
эти строки принадлежат описательному слою, а не операционному изменению асети.

Связанные формулы:

R7 вводит фигурную пучковую нотацию.

Слой развития:

операции над входящими и исходящими связями.

## R9. Начало и конец акорня

Формула:

```text
∞♀ : [⟼]♀
♂∞ : ♂[⟼]
```

Вводимые различия:

`∞♀` как начало акорня и `♂∞` как конец акорня.

Чтение:

начало акорня извлекается как начало конкретной связи `[⟼]`;
конец акорня извлекается как конец конкретной связи `[⟼]`.

Слои различения:

`∞♀` и `♂∞` принадлежат слою формы связи;
конкретная связь `[⟼]` принадлежит квадратной нотации;
смысл связи `(⟼)` принадлежит формальной нотации.

Связанные формулы:

R10 разводит смысл связи `(⟼)` и конкретную связь `[⟼]`.

Слой развития:

полная модель извлечения начала и конца для произвольных форм связи.

## R10. Смысл связи и конкретная связь

Формула:

```text
(⟼) : [] ⟼ []
[⟼] : ∞♀ ⟼ ♂∞
```

Вводимые различия:

`(⟼)` как смысл связи и `[⟼]` как конкретную связь.

Чтение:

`(⟼)` задаёт смысл связи как формы связи одной связи с другой связью;
`[⟼]` задаёт конкретную связь как связь начала акорня с концом акорня.

Слои различения:

знак `⟼` принадлежит слою формы связи;
смысл `(⟼)` принадлежит формальной нотации;
конкретная связь `[⟼]` принадлежит квадратной нотации.

Связанные формулы:

R9 вводит начало и конец акорня;
R11 вводит инверсию конкретной связи.

Слой развития:

как будущий апрувер различает знак, смысл знака, конкретную связь знака и результат применения смысла.

## R11. Инверсия формы связи

Формула:

```text
¬[] : ♂[] ⟼ []♀
¬[⟼] : ♂[⟼] ⟼ [⟼]♀
¬[⟼] = ♂∞ ⟼ ∞♀
```

Вводимые различия:

`¬` как инверсию формы связи и конкретной связи.

Чтение:

инверсия формы связи есть связь её конца с её началом;
поэтому конкретная связь `[⟼] : ∞♀ ⟼ ♂∞` связана с инверсией формулой `¬[⟼] = ♂∞ ⟼ ∞♀`.

Слои различения:

`¬` применяется к смыслу и к результату применения смысла;
конкретная связь знака принадлежит отдельному слою;
абит `0` вводится формулой `0 : [↛]` в R15, а его связь с инверсией удерживается через `↛ : ¬[⟼]`.

Связанные формулы:

R10 вводит конкретную связь `[⟼]`;
R14 вводит несвязь `↛ : ¬[⟼]`.

Слой развития:

строгие границы применения `¬` к смыслу, результату применения смысла и конкретной связи.

## R12. Смысл равенства

Формула:

```text
(=) : {[]♀ = []♀, ♂[] = ♂[]}
```

Вводимые различия:

`(=)` как смысл равенства.

Чтение:

смысл равенства определяется совпадением начал и совпадением концов сравниваемых форм связи;

```text
A = B
⇔
A♀ = B♀
и
♂A = ♂B
```

повторные `[]` в этой формуле читаются позиционно, а не как тавтология одного и того же места.

Слои различения:

смысл равенства `(=)` принадлежит формальной нотации;
начала `[]♀` и концы `♂[]` принадлежат слою формы связи;
результат сравнения `[] = []` относится к слою развития.

Связанные формулы:

R13 вводит неравенство как инверсию смысла равенства.

Слой развития:

полная модель результата сравнения и тип результата `[] = []`.

## R13. Неравенство как инверсия смысла равенства

Формула:

```text
(!=) : ¬(=)
[] != [] : ¬([] = [])
```

Вводимые различия:

`(!=)` как смысл неравенства и `!=` как запись результата конкретного сравнения.

Чтение:

неравенство является инверсией смысла равенства;
конкретная запись `[] != []` читается как инверсия результата сравнения `[] = []`.

Слои различения:

смысл неравенства `(!=)` принадлежит формальной нотации;
результат конкретного сравнения `[] != []` принадлежит слою результата;
конкретная связь знака равенства `[=]`, если будет введена, принадлежит отдельному слою и удерживается отдельно от `(=)`.

Связанные формулы:

R11 вводит инверсию `¬`;
R12 вводит смысл равенства `(=)`.

Слой развития:

как будущий апрувер различает смысл равенства, конкретную связь знака равенства и результат конкретного сравнения.

## R14. Несвязь

Формула:

```text
↛ : ¬[⟼]
```

Вводимые различия:

`↛` как несвязь, введённую через инверсию конкретной связи.

Чтение:

`↛` является промежуточным смыслом для абита `0`;
он удерживает различие между инверсией конкретной связи и практической записью отсутствия связи.

Слои различения:

несвязь `↛` принадлежит формальной нотации;
абит `0` вводится формулой `0 : [↛]` в R15;
пустой пучок `{}` принадлежит пучковой нотации.

Связанные формулы:

R11 вводит инверсию `¬`;
R15 связывает несвязь с абитом `0`.

Слой развития:

строгая семантика `↛`.

## R15. Абиты квадратной нотации

Формула:

```text
[ : ∞♀
] : ♂∞
1 : [⟼]
0 : [↛]
```

Вводимые различия:

`[`, `]`, `1`, `0` как абиты квадратной нотации.

Чтение:

`[` — абит начала;
`]` — абит конца;
`1` — абит конкретной связи;
`0` — абит несвязи / отсутствия связевой формы в сериализации.

Слои различения:

абиты `[`, `]`, `1`, `0` принадлежат квадратной нотации;
`∞` принадлежит слою знака полного самозамыкания;
`[` и `]` удерживаются отдельно от фигурных и круглых скобок;
`0` вводится формулой `0 : [↛]`, а не как прямая инверсия `1`.

Связанные формулы:

R9 вводит начало и конец акорня;
R14 вводит несвязь `↛`.

Слой развития:

связь `0` с сериализацией отсутствия и полная модель четверичной записи.

## Слой развития

Следующие темы образуют слой развития поверх корневой системы формул:

- переменные как производный механизм;
- подстановка;
- операции над всеми входящими и исходящими связями в пучковой нотации;
- статус пустой круглой формы `()`;
- полная формализация позиционного чтения повторных `[]`;
- полная модель результата сравнения;
- строгая семантика `↛`;
- полная модель `:` для будущего апрувера.

Они ведутся в [Открытых вопросах новой аксиоматики МТС](../research/Открытые%20вопросы%20новой%20аксиоматики%20МТС.md).
