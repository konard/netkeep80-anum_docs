# Шаблон аксиом МТС

Статус: актуальное, нормативное.

Аксиома МТС входит в текущую систему через формулу формальной нотации. Документ с аксиомой должен пояснять формулу, но не заменять её внешним механизмом.

## Обязательная структура

```text
Название
Статус
Формула
Чтение
Вводимые различия
Слои различения
Связанные формулы
Проверки
```

## Формула

Формула должна быть строкой из `tests/mtc_formulas.mtc` или явно зависеть от такой строки. Корневая система формул является корневой библиотекой апрувера.

## Чтение

Чтение фиксирует роль формулы в текущей МТС:

```text
связь — единственная форма существования
существовать — значит быть связью
смысл не существует отдельно от связи
связь и есть смысл в своей различённой форме
```

Если формула касается несвязи, чтение должно явно фиксировать:

```text
несвязь не существует в натуре
смысл несвязи выражается связью
0 — абит связи, несущей смысл несвязи
↛ — смысл несвязи
```

## Равенство

Если формула касается `=`, чтение должно фиксировать:

```text
равенство фиксирует совпадение форм связей
равенство не является простой идентичностью определения
формы связей являются видами самозамыканий
рекурсивная процедура сравнения различает формы рекурсий
равенство не требует бесконечного раскрытия рекурсивных связей
```

## Скобочные нотации

```text
(...) — круглая формальная нотация
[...] — квадратная ачисловая нотация
{...} — пучковая нотация
```

```text
[] — минимальная завершённая форма одной связи
() — минимальная формальная форма смысла
{} — пустой пучок связей
```
