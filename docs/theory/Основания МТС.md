# Основания МТС

Статус: актуальное.

## Назначение

Документ фиксирует новую базовую рамку issue #42. Он нужен как короткая точка входа перед чтением рабочей системы аксиом и спецификаций нотации.

## Постулат

```text
всё есть связь
```

Это не означает, что все записи в репозитории находятся на одном уровне. МТС различает связь, смысл связи, знак смысла, формальную запись, шаблон поиска, ачисло и асеть.

## Конвейер уровней

```text
связь в натуре
→ смысл связи
→ знак смысла
→ формальная запись смысла
→ шаблон поиска формы
→ возможная сериализация в ачисло
```

Главная ошибка старых текстов — смешение этих уровней. Новая переработка устраняет именно это смешение.

## Базовые различения

| Различение | Новая фиксация |
|------------|----------------|
| Ачисла / формальная нотация | Ачисла описывают структуры связей; формальная нотация описывает смыслы и шаблоны смыслов |
| Знак / связь | Знак задаёт форму поиска, а не обязательно указывает на одну готовую связь |
| `{}` / пустота | `{}` означает поиск без фильтра, а не пустое множество |
| `[]` / формульные скобки | `[]` принадлежат ачислам и сериализации |
| Аксиома / частный случай | Аксиома должна вводить вид формы смысла, а не накапливать частные случаи |

Запрещённые чтения `{}` фиксируются явно:

```text
{} ≠ пустое множество
{} ≠ пустой результат поиска
{} ≠ несвязь
{} ≠ 0
```

## Определение

Рабочая форма определения:

```text
s : F
```

Чтение:

```text
знак s вводит смысл, определяемый формой F
```

Более точно:

```text
s — знак для смысла, найденного по шаблону формы F
```

## Акорень

Новая основная формула:

```text
∞ : {} = {} ⟼ {}
```

Она означает, что `∞` задаёт смысл полной самозамкнутости. Только после исполнения шаблона появляется привычная запись:

```text
∞ : ∞ ⟼ ∞
```

Внутри одного исполнения шаблона все одинаковые вхождения `{}` относятся к одной и той же связи-кандидату.

То есть эта формула ищет один `X`, для которого `X = X ⟼ X`, а не три независимых связи `A`, `B`, `C`, для которых `A = B ⟼ C`.

Исполнение шаблона — это нахождение связи-кандидата, удовлетворяющей ограничениям формы, и связывание найденного смысла с вводимым знаком.

## Архитектурный принцип

Актуальная МТС должна быть меньше и строже старой. Если старая конструкция требует много исключений или смешивает уровни, она должна быть переписана, перенесена в архив или явно помечена как историческая.
