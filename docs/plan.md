# План активной документации МТС

## Цель

Держать активную документацию МТС в единой положительной форме: активные документы описывают текущую систему через положительные различия, корневой fixture остаётся машинно-читаемой библиотекой формул, тесты проверяют актуальные формулы, слои чтения и согласованность документов.

## Текущее состояние

```text
всё есть связь

формальная нотация МТС — система смысловых различий

строковое ачисло
→ последовательность различий
→ формула
→ интерпретация формулы
→ связь / асеть связей
```

Первичные скобочные нотации:

```text
(...) — явная формальная форма / группировка формы
[...] — нотация ачисла; форма одной связи
{...} — пучковая нотация; форма пучка / асети связей
```

Корневая библиотека апрувера:

```text
каждая аксиома имеет формулу;
система формул аксиом решается одновременно;
система формул аксиом составляет корневую библиотеку апрувера.
```

1. Полная формализация позиционного чтения повторных `[]`.
2. Полная модель результата сравнения и тип результата `[] = []`.
3. Строгая семантика `↛` и связь `0` с сериализацией отсутствия.
4. Разрешено ли пустое `()` как самостоятельная форма.
5. Будущая теория переменных и подстановки.
6. Операции над всеми входящими и исходящими связями в пучковой нотации.
7. Операционное изменение асети как остенсивной структуры.
8. Полная модель `:`.
9. Будущий апрувер, решающий систему формул одновременно.
