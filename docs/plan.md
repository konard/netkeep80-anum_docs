# План переработки МТС по issue #42

## Цель

Пересобрать основания МТС так, чтобы актуальная документация стала короче, чище и не смешивала:

- формальную нотацию смыслов;
- шаблонный поиск;
- ачисла и абиты;
- асеть как остенсивную модель;
- исторические версии аксиом.

## Критерий готовности

1. README показывает статус переработки по issue #42.
2. Актуальная теория начинается с новой рамки, а не со старой таблицы А0-А16.
3. Формальная нотация определяет `{}` как шаблонный поиск без фильтра.
4. Квадратные скобки закреплены за ачислами.
5. Новая аксиома акорня записана как `∞ : {} = {} ⟼ {}`.
6. Повторные `{}` внутри одного исполнения шаблона явно связываются с одной связью-кандидатом.
7. Старые тексты вынесены из активных разделов и явно воспринимаются как архивные.
8. Код парсеров и конвертеров не переписывается до стабилизации новой нотации.
