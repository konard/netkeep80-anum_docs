# План наведения порядка в репозитории anum_docs

## Цель

Привести репозиторий в порядок: структурировать файлы, переместить устаревшие материалы в архив, и подготовить чистовой вариант Метатеории связей (МТС).

---

## Текущее состояние

### Проблемы
1. **Корневая директория перегружена** — 11 `.md` файлов разной степени готовности лежат в корне
2. **Неоднозначное именование** — файлы `1.md` и `2.md` не имеют осмысленных названий
3. **Дублирование контента** — есть черновик, два чистовика и множество промежуточных версий
4. **Папка `faq/` содержит FAQ** — но README указывает на `ЧАВО/` как желаемое название
5. **Папка `Чистовик/`** содержит 3 файла с финальными вариантами
6. **Нет папки `archive/`** — для хранения старых файлов, хотя README её предусматривает
7. **Файлы `1.jpeg`, `test.bat`, `.gitkeep`** — разбросаны в корне

## План действий

### Этап 1: Создание архива ✅ → `archive/`
- [ ] Создать папку `archive/`
- [ ] Переместить все черновые/рабочие `.md` файлы из корня в `archive/`:
  - `Черновик МТС.md`
  - `Введение в МТС.md`
  - `Нотации МТС.md`
  - `Система аксиом Метатеории Связей.md`
  - `Система логических уравнений МТС.md`
  - `Разрыв между знаком и связью.md`
  - `Аксиоматическое определение начала и конца связи.md`
  - `О природе самозамыкания и его возможности.md`
  - `Требования к изложению системы аксиом.md`
  - `смысл.md`
  - `1.md`
  - `2.md`
- [ ] Переместить `1.jpeg` → `pics/1.jpeg`
- [ ] Переместить `test.bat` → `tests/test.bat`
- [ ] Удалить `.gitkeep` (репозиторий уже не пустой)

### Этап 2: Переименование и реорганизация FAQ
- [ ] Переименовать `faq/` → оставить как есть (или переименовать в `ЧАВО/` по желанию автора)
- [ ] Переместить содержимое `Чистовик/` → `docs/theory/`
- [ ] Убедиться, что `docs/` структурирована согласно README

### Этап 3: Написание чистовика МТС
- [ ] Изучить все существующие чистовые варианты в `Чистовик/`:
  - `Метатеория связей - Чистовой вариант.md` (829 строк)
  - `Метатеории связей.md` (792 строки)
  - `Анализ формулы связи ♂∞♀.md` (38 строк)
- [ ] Изучить черновик `Черновик МТС.md` (905 строк)
- [ ] Изучить методологические требования из `Требования к изложению системы аксиом.md`
- [ ] Используя шаблон из `docs/theory/Шаблон аксиом МТС.md`, написать единый чистовик
- [ ] Чистовик должен содержать:
  - Введение (цель, базовые термины, два домена)
  - Полную систему аксиом в едином формате
  - Следствия и теоремы
  - Примеры и применения
- [ ] Разместить чистовик в `docs/theory/Метатеория связей.md`

### Этап 4: Обновление README.md
- [ ] Обновить структуру директорий в README
- [ ] Убрать устаревшие ссылки
- [ ] Добавить описание новой структуры

### Этап 5: Финальная проверка
- [ ] Убедиться, что корень чистый (только README.md, LICENSE, .gitignore)
- [ ] Убедиться, что все файлы на месте
- [ ] Проверить, что парсеры и тесты работают
- [ ] Убедиться, что PDF-файлы в `pdf/` актуальны
