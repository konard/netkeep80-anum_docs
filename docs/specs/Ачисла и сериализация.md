# Ачисла и сериализация

## Статус

Ачисла остаются практическим слоем описания структур связей. Issue #42 не отменяет ачисла, но отделяет их от формальной нотации смыслов.

## Абиты

Четыре базовых абита:

```text
[  начало сериализуемой структуры
]  конец сериализуемой структуры
1  наличие связи / единица сериализации
0  отсутствие связи / нуль сериализации
```

В новой рамке важно различать:

```text
[ и ]    — абиты ачисел
{[} и {]} — смысловые ссылки на эти абиты
```

## Запрет смешения

`[` и `]` не используются как:

- формульная группировка;
- экранирование оператора `⟼`;
- универсальный контекст;
- кавычки для знака.

Для формальной группировки используются круглые скобки. Для смысла знака используется `{s}`.

## Отношение к старой записи `[⟼]`

Запись `[⟼]` может описывать исторический или абитово-остенсивный способ указать на связь. Она больше не является базовым синтаксисом ядра.

В новой записи смысл конструктора связи выражается так:

```text
{⟼} : {[} ⟼ {]}
```
