# Ачисла и сериализация

## Статус

Статус: актуальное для практической сериализации.

Ачисла остаются практическим слоем описания структур связей. Они отделены от корневой системы формул, но квадратная нотация `[...]` теперь явно описывается как контейнер формы одной связи.

## Квадратный контейнер

В формальной нотации текущего ядра:

```text
[] — пустая форма одной связи
[] = ∞ — рабочая корневая фиксация
```

Квадратные скобки читаются как границы контейнера формы одной связи. Сам контейнер `[]` входит в корневой fixture, а смысл отдельных границ `[` и `]` остаётся открытым вопросом.

## Практические абиты

Четыре базовых абита практической сериализации:

```text
[  начало сериализуемой структуры
]  конец сериализуемой структуры
1  наличие связи / единица сериализации
0  отсутствие связи / нуль сериализации
```

Эти абиты нужны конвертерам и сериализованным ачислам. Их практическая роль не делает их автоматически отдельными аксиомами корневой формальной нотации.

## Запрет смешения

`[` и `]` не используются как:

- круглые скобки формальной группировки;
- фигурные скобки пучковой нотации;
- кавычки для знака;
- готовый способ говорить о смысле отдельной границы.

Для формальной группировки используется `(...)`. Для формы одной связи используется `[...]`. Для пучка / асети связей используется `{...}`.
