# Ачисла и сериализация

## Статус

Статус: актуальное для практической сериализации.

Ачисла остаются практическим слоем описания структур связей. Они отделены от корневой системы формул, но квадратная нотация `[...]` теперь явно описывается как контейнер формы одной связи.

## Квадратный контейнер

В формальной нотации текущего ядра:

```text
[] — пустая форма одной связи
[] = ∞ — рабочая корневая фиксация
```

[] является минимальной ачисловой записью акорня. ∞ не является абитом: это знак полного самозамыкания, выражаемый через `[] = ∞`.

## Абиты квадратной нотации

Абиты квадратной нотации вводятся формулами корневой системы:

```text
[ : ∞♀
] : ♂∞
1 : [⟼]
↛ : ¬[⟼]
0 : [↛]
```

Чтение:

```text
[ и ] являются абитами начала и конца
1 вводится как абит конкретной связи
0 вводится как абит несвязи
```

`1 : [⟼]` связывает абит `1` с конкретной связью. `0 : [↛]` связывает абит `0` с несвязью. Промежуточная формула `↛ : ¬[⟼]` удерживает различие между инверсией конкретной связи и абитом отсутствия связевой формы в сериализации.

`0` не отождествляется напрямую с инверсией связи и не становится пустым пучком.

Эти абиты квадратной нотации входят в рабочий корень, а практические конвертеры используют их для обратимой сериализации.

## Запрет смешения

`[` и `]` не используются как:

- круглые скобки формальной группировки;
- фигурные скобки пучковой нотации;
- кавычки для знака;
- внешний механизм смысловой ссылки.

Для формальной группировки используется `(...)`. Для формы одной связи используется `[...]`. Для пучка / асети связей используется `{...}`.
