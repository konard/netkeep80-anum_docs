# Ачисла и сериализация

## Статус

Статус: актуальное для практической сериализации.

Ачисла остаются практическим слоем описания структур связей. Они отделены от формальной нотации смыслов, но имеют явные переходы к формулам текущего ядра.

## Абиты квадратной нотации

Четыре базовых абита:

```text
[  начало сериализуемой структуры
]  конец сериализуемой структуры
1  наличие связи / единица сериализации
0  отсутствие связи / нуль сериализации
```

В текущей рамке:

```text
[ и ] являются абитами;
[] является минимальной ачисловой записью акорня;
∞ не является абитом;
1 вводится как абит конкретной связи;
0 вводится как абит несвязи.
```

Формулы абитов:

```text
[ : ∞♀
] : ♂∞
1 : [⟼]
0 : [↛]
```

## Канонический блок перехода

Слой ачисел связан с формальной нотацией через текущий корневой блок:

```text
∞♀ : [⟼]♀
♂∞ : ♂[⟼]

(⟼) : [] ⟼ []
[⟼] : ∞♀ ⟼ ♂∞

¬[] : ♂[] ⟼ []♀
¬[⟼] : ♂[⟼] ⟼ [⟼]♀
¬[⟼] : ♂∞ ⟼ ∞♀

(=) : {[]♀ = []♀, ♂[] = ♂[]}
(!=) : ¬(=)
[] != [] : ¬([] = [])

↛ : ¬[⟼]

[ : ∞♀
] : ♂∞
1 : [⟼]
0 : [↛]
```

Этот блок фиксирует смысл связи, конкретная связь, инверсия формы связи, смысл равенства, смысл неравенства и абиты квадратной нотации.

## `[]` и акорень

`[]` — пустая форма одной связи и минимальная ачисловая запись акорня.

```text
[] = ∞
```

Эта запись относится к слою сериализации: `∞` остаётся смыслом полного самозамыкания, а не абитом.

## Запрет смешения

`[` и `]` не используются как:

- формульная группировка;
- универсальный контекст;
- кавычки для знака.

Для формальной группировки используются круглые скобки. Для смысла связи используется `(⟼)`. Для конкретной связи используется `[⟼]`.

## Несвязь и ноль

`↛` вводится как несвязь:

```text
↛ : ¬[⟼]
```

`0` записывает несвязь на уровне сериализации:

```text
0 : [↛]
```

`0` не является пустым результатом поиска и не должен прямо отождествляться с инверсией связи без промежуточного смысла `↛`.

Правило для отрицания:

```text
¬[=] не означает !=
```

Инверсия конкретной связи знака равенства не является смыслом неравенства.
