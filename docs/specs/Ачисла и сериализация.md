# Ачисла и сериализация

## Статус

Статус: актуальное для практической сериализации.

Ачисла остаются практическим слоем описания структур связей. Они отделены от формальной нотации смыслов.

## Абиты

Четыре базовых абита:

```text
[  начало сериализуемой структуры
]  конец сериализуемой структуры
1  наличие связи / единица сериализации
0  отсутствие связи / нуль сериализации
```

В новой рамке важно различать:

```text
[ и ]       — абиты ачисел
⟦[⟧Q и ⟦]⟧Q — смысловые ссылки на эти абиты в четверичной нотации
```

## Запрет смешения

`[` и `]` не используются как:

- формульная группировка;
- экранирование оператора `⟼`;
- универсальный контекст;
- кавычки для знака.

Для формальной группировки используются круглые скобки. Для смысла знака используется `⟦s⟧N`.

## Отношение к скобочной записи связи

Скобочная запись связи описывает абитово-остенсивный способ указать на связь. Она не является синтаксисом актуального ядра.

В новой записи смысл конструктора связи выражается так:

```text
⟦[⟧Q⟦]⟧Q = ⟦[⟧Q ⟼ ⟦]⟧Q
⟦⟼⟧F : ⟦[⟧Q⟦]⟧Q
⟦⟼⟧F = ⟦[⟧Q ⟼ ⟦]⟧Q
```

Здесь `⟦[⟧Q⟦]⟧Q` — последовательность смыслов абитов начала и конца. По правилу последовательности она читается как связь `⟦[⟧Q` с `⟦]⟧Q`.
