# Слои нотации МТС

Статус: актуальное.

## Назначение

Документ разделяет способы записи, чтобы строка, формула, форма одной связи, пучок и асеть не смешивались в один уровень.

## Слои

| Слой | Что описывает | Пример |
|------|---------------|--------|
| Связь в натуре | Саму связность до записи | направленная связь в асети |
| Строковое ачисло | Текстовую запись формулы | строка с формулой МТС |
| Формальная форма | Последовательность различий | `([]) = []` |
| Форма одной связи | Результат чтения квадратного контейнера | `[]`, `[][]` |
| Конкретная связь | Квадратная запись связи между началом и концом акорня | `[⟼]` |
| Смысл связи | Формальная форма связности одной связи с другой | `(⟼)` |
| Пучковая форма | Результат чтения фигурного контейнера | `{[]}`, `{[], [][]}` |
| Асеть связей | Остенсивную структуру связей | пучок раскрытых связей |
| Четверичная сериализация | Практическое кодирование | `[10]` |

## Таблица первичных нотаций

| Нотация | Что описывает | Ближайший результат |
|---------|---------------|---------------------|
| `(...)` | формальную форму / группировку | одно формальное различие |
| `[...]` | форму одной связи | одна связь |
| `{...}` | пучок / асеть связей | пучок связей |

## Конвейер

```text
строковое ачисло
→ последовательность различий
→ формула
→ интерпретация формулы
→ связь / асеть связей
```

Практическая четверичная сериализация остаётся отдельным слоем. Она может кодировать структуры, но не заменяет формулы корневой системы.

## Правило переходов

Нельзя переносить знак из одного слоя в другой без явного перехода.

Примеры:

- квадратный контейнер `[]` задаёт форму одной связи, а `[`, `]`, `1`, `0` вводятся как абиты квадратной нотации;
- `(⟼)` задаёт смысл связи, а `[⟼]` задаёт конкретную связь;
- фигурный контейнер `{}` задаёт пустой пучок связей, а не форму одной связи;
- круглые скобки группируют уже имеющуюся формальную форму;
- ачисло не является формулой МТС, хотя может кодировать структуру, связанную с формулой.

## Практическое следствие

Документ или код должен явно указывать, с каким слоем он работает. Если слой не указан, запись считается неоднозначной и не должна использоваться как спецификация.
