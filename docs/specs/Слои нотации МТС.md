# Слои нотации МТС

Статус: актуальное, нормативное.

## Основные слои

```text
formal_form — круглая формальная нотация
single_connection_form — форма одной связи
quaternary_serialization — квадратная ачисловая нотация
bundle_form — пучковая нотация
```

## Скобочные нотации

```text
(...) — круглая формальная нотация
[...] — квадратная ачисловая нотация
{...} — пучковая нотация
```

```text
[] — минимальная завершённая форма одной связи
() — минимальная формальная форма смысла
{} — пустой пучок связей
```

## Онтологический слой

связь — единственная форма существования. существовать — значит быть связью. Смысл не существует отдельно от связи, потому что связь и есть смысл в своей различённой форме.

Акорень несёт смысл смысла.

## Несвязь

Несвязь не существует в натуре. Смысл несвязи выражается связью.

```text
↛ — смысл несвязи
0 — абит связи, несущей смысл несвязи
```

Абит 0 не является отсутствием связи в натуре.

## Инверсия

Инверсия связи меняет направление натуральной связи. Инверсия смысла меняет смысл на обратный. Обратное направление связи не является отсутствием связи.

## Равенство

Равенство фиксирует совпадение форм связей. Равенство не является простой идентичностью определения. Формы связей являются видами самозамыканий. Рекурсивная процедура сравнения различает формы рекурсий. Равенство не требует бесконечного раскрытия рекурсивных связей.
