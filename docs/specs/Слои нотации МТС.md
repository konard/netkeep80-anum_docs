# Слои нотации МТС

Статус: актуальное.

## Назначение

После issue #42 основная задача — не дать разным способам записи снова смешаться в один уровень.

## Слои

| Слой | Что описывает | Пример |
|------|---------------|--------|
| Связь в натуре | Саму связность до записи | направленная связь в асети |
| Смысл связи | Различённую форму связи | полное самозамыкание |
| Знак смысла | Имя или знак для смысла | `∞`, `{⟼}` |
| Формальная запись | Шаблон поиска смысла | `∞ : {} = {} ⟼ {}` |
| Ачисло | Сериализованную структуру | `[10]` |
| Асеть | Остенсивную модель | узлы и направленные рёбра |

## Правило переходов

Нельзя переносить знак из одного слоя в другой без явного перехода.

Примеры:

- `[` как абит не становится формальной скобкой.
- `⟼` как конструктор не становится самостоятельной связью без смысловой ссылки `{⟼}`.
- `{}` как шаблон поиска не становится пустым результатом поиска.
- Ачисло не является формулой МТС, хотя может кодировать структуру, связанную с формулой.

## Конвейер

```text
абитовое ачисло
→ строковое ачисло
→ формальная запись
→ шаблон / формула
→ связь-смысл
→ асеть / структура связей
```

Этот конвейер описывает возможные переходы, а не автоматическое тождество всех уровней.

## Практическое следствие

Документ или код должен явно указывать, с каким слоем он работает. Если слой не указан, запись считается неоднозначной и не должна использоваться как спецификация.
