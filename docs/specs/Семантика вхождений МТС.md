# Семантика вхождений МТС

Статус: актуальное, нормативное.

## Основное правило

видимый знак не равен вхождению знака.

Один и тот же видимый символ может иметь разные роли в разных нотациях и разных позициях формулы.

## Базовые роли вхождений

### container-boundary

Скобка как граница контейнера.

Примеры:

```text
[]
[1]
[0]
{}
()
```

В `[1]` символы `[` и `]` являются container-boundary квадратной формы.

### literal-abit

Скобка как буквальный абит.

```text
([) : (♀∞)
(]) : (∞♂)
```

В `([)` символ `[` не открывает квадратный контейнер. Он читается как буквальный левый квадратный абит внутри круглой формальной нотации.

В `(])` символ `]` не закрывает квадратный контейнер. Он читается как буквальный правый квадратный абит внутри круглой формальной нотации.

### one-link-form

```text
[]
```

`[]` — минимальная завершённая форма одной связи.

### link-pole-form

```text
♀[] : ♀[] = ♀[] ⟼ []
[]♂ : []♂ = [] ⟼ []♂
```

`♀[]` — начало формы одной связи, `[]♂` — конец формы одной связи в актуальной ориентации полюсов: `♀F` — начало, `F♂` — конец.

Роли:

```text
♀[] — начало формы связи
[]♂ — конец формы связи
```

Старое чтение `[]♀` и `♂[]` не используется.

### abit-form

```text
[1] : (⟼)
[0] : (↛)
```

`[1]` — квадратная форма абита связи.

`[0]` — квадратная форма абита несвязи.

`0 — абит связи, несущей смысл несвязи`, а `↛ — смысл несвязи`.

### formal-form

Круглая формальная форма.

```text
(⟼)
(↛)
([)
(])
(♀∞ ⟼ ∞♂)
(∞♂ ⟼ ♀∞)
```

### empty-formal-form

```text
() : ♀() ⟼ ()♂
```

`()` — минимальная формальная форма смысла.

Роли:

```text
() — empty-formal-form
♀() — начало формальной формы смысла
()♂ — конец формальной формы смысла
♀() ⟼ ()♂ — связь смыслов
```

### grouped-form

`(A)` — grouped-form, если внутри круглой формы уже есть формальная форма `A`.

Reader должен различать `()` как empty-formal-form и `(A)` как grouped-form.

### bundle-form

```text
{}
{[]}
```

`{}` — пустой пучок связей.

## Локальный контекст после двоеточия

Формула вида `A : F` вводит различие `A` через локальную форму `F`.

```text
∞ : [] = [] ⟼ []
```

Повторные `[]` в правой части читаются в локальном контексте формулы.

## Вхождения в равенстве

```text
(=) : {♀[] = ♀[], []♂ = []♂}
```

Повторные `♀[]` и `[]♂` не являются одной текстовой переменной. Это позиционные формы, сравниваемые по смыслу, то есть по форме самозамыкания: начала сравниваются с началами, концы — с концами.

Равенство фиксирует совпадение форм связей. Равенство не является простой идентичностью определения. Формы связей являются видами самозамыканий. Рекурсивная процедура сравнения различает формы рекурсий. Равенство не требует бесконечного раскрытия рекурсивных связей.

## Требования к reader

Reader должен различать:

```text
[ как container-boundary
[ как literal-abit
] как container-boundary
] как literal-abit
[] как one-link-form
[1] как abit-form
[0] как abit-form
{} как bundle-form
() как empty-formal-form
(A) как grouped-form
```

Нельзя читать:

```text
([) как незакрытый квадратный контейнер
(]) как лишнюю закрывающую квадратную скобку
[1] как список из одного элемента
[0] как пустоту
{} как форму одной связи
[] как пустой пучок
```

## Онтологическая связь ролей

связь — единственная форма существования. существовать — значит быть связью. Смысл не существует отдельно от связи, а связь и есть смысл в своей различённой форме.

Несвязь не существует в натуре. Смысл несвязи выражается связью.
