# Шаблонный поиск МТС

Статус: рабочее.

## Назначение

Этот документ сохраняет название рабочей темы, но в текущем ядре речь идёт о шаблонном чтении форм связей, а не об отдельном универсальном слоте поиска.

Шаблонное чтение означает:

```text
формула задаёт форму связи,
а интерпретация формулы распознаёт связь или асеть связей.
```

Главный пример:

```text
∞ : [] = [] ⟼ []
```

Здесь `[]` — пустая форма одной связи в квадратной нотации. Повторные пустые формы внутри правой части читаются как повтор одного образца в рамках этой формулы. При этом последовательная запись `[][]` читает две позиции формы как связь.

## Повтор и позиция

Здесь действует правило: внутри формулы после `:` повторные `[]` могут читаться как один образец:

```text
∞ : [] = [] ⟼ []
```

Второе правило: в последовательности `[][]` эти же `[]` читаются как позиции:

```text
[][] : [] ⟼ []
[][] = [] ⟼ []
```

Третье правило: в формулах равенства повторные `[]` могут читаться как позиционные сравниваемые формы:

```text
(=) : {[]♀ = []♀, ♂[] = ♂[]}
[] != [] : ¬([] = [])
```

Эта разница остаётся открытым формальным вопросом для будущего апрувера, но корневой fixture уже фиксирует основные стороны различия.

## Группировка

Круглые скобки фиксируют границу уже собранной формы:

```text
([]) = []
([][]) = [][]
([] ⟼ []) = [] ⟼ []
```

Без явной правой группировки последовательность из трёх форм собирается слева:

```text
[][][] : ([][]) ⟼ []
[][][] = ([] ⟼ []) ⟼ []
[][][] = [] ⟼ [] ⟼ []
```

Правая группировка записывается явно и отличается от левой сборки:

```text
[]([][]) : [] ⟼ ([][])
[][][] != []([][])
[][][] != [] ⟼ ([] ⟼ [])
```

## Исполнение

На текущем этапе fixture не обязан доказывать все формулы как математические следствия. Он фиксирует корневую библиотеку для будущего апрувера:

1. список формул;
2. допустимые различия;
3. различие между повтором в шаблоне и позицией в последовательности;
4. связь формальной группировки, формы одной связи и пучковой формы.

## Что вынесено за пределы ядра

В текущем документе не вводятся:

- универсальный внешний placeholder;
- переменные как первичная сущность;
- подстановка;
- полная модель результата сравнения;
- строгая семантика несвязи `↛`;
- операционное чтение пучковых выражений.
