# Шаблонный поиск МТС

Статус: рабочее.

## Основная идея

Шаблонный поиск — это способ описать смысл через форму, которой должна удовлетворять связь-кандидат.

```text
{} — шаблонный поиск без фильтра
```

`{}` не содержит результата. Оно обозначает место поиска, которое получает ограничения из окружающей формулы.

## Связывание повторных `{}`

Внутри одного исполнения шаблона все одинаковые вхождения `{}` относятся к одной и той же связи-кандидату.

Это правило делает аксиому акорня однозначной. Она читается не как поиск трёх независимых связей `A`, `B`, `C`, для которых `A = B ⟼ C`, а как поиск одного кандидата `X`, для которого `X = X ⟼ X`.

## Позиции в последовательности

Последовательная запись имеет отдельное правило чтения.

В последовательностной записи `{}{}...` каждое вхождение `{}` задаёт отдельную позицию кандидата.

Поэтому:

```text
{}{} : {} ⟼ {}
```

читается как позиционная пара `AB`, где первая позиция даёт начало связи, а вторая позиция даёт конец связи. Это не конфликтует с правилом акорня, потому что `{}{}...` является последовательностной записью, а не повтором одного кандидата внутри условия одной формы.

Для трёх позиций действует прямоассоциативное чтение:

```text
{}{}{} : ({} ⟼ {}) ⟼ {}
{}{}{} = {} ⟼ {} ⟼ {}
{}{}{} != {} ⟼ ({} ⟼ {})
```

## Пример акорня

```text
∞ : {} = {} ⟼ {}
```

Чтение:

```text
найти смысл, для которого связь-кандидат тождественна связи этой же формы с самой собой;
ввести для найденного смысла знак ∞.
```

После исполнения шаблона:

```text
∞ = ∞ ⟼ ∞
```

## Исполнение шаблона

Исполнение шаблона — это нахождение связи-кандидата, удовлетворяющей ограничениям формы, и связывание найденного смысла с вводимым знаком.

Минимальная схема:

```text
шаблон → кандидат → ограничение формы → найденный смысл → вводимый знак
```

Для акорня это означает:

```text
найти X, такой что X = X ⟼ X;
обозначить найденный смысл знаком ∞;
после этого допустима запись ∞ = ∞ ⟼ ∞.
```

## Отличие от пустоты

```text
{} ≠ пустое множество
{} ≠ пустой результат поиска
{} ≠ несвязь
{} ≠ 0
```

Также `{}` не означает:

- пустой набор;
- пустую асеть.

Пустой результат поиска должен быть введён отдельно, если он понадобится.

## Смысловая ссылка

Запись `{s}` означает смысл знака `s`.

```text
{[} : ∞♀
{]} : ♂∞
{[}{]} = {[} ⟼ {]}
{⟼} : {[}{]}
{⟼} = {[} ⟼ {]}
```

Это не контейнер и не множество. Это способ поднять знак в слой смыслов.

`{}` и `{s}` — разные конструкции, хотя обе используют фигурные скобки:

```text
{}  — пустой фильтр поиска / связь-кандидат шаблона
{s} — смысловая ссылка на знак s
```

{} не является частным случаем `{s}`.
{s} не является поиском без фильтра.
