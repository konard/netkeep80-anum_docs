# Шаблонное чтение МТС

Статус: актуальное, нормативное.

## Назначение

Шаблонное чтение описывает локальные вхождения форм внутри формулы. Оно не вводит отдельную нотацию поверх текущего ядра.

## Локальная форма после двоеточия

В формуле `A : F` правая часть `F` задаёт локальную форму чтения различия `A`.

```text
∞ : [] = [] ⟼ []
```

Повторные `[]` в этой формуле читаются как связанные вхождения локальной формы одной связи.

## Позиционные формы

В других формулах повторный видимый знак может быть другим вхождением. Видимый знак не равен вхождению знака.

```text
(=) : {[]♀ = []♀, ♂[] = ♂[]}
```

Повторные `[]` здесь являются позиционными формами сравнения.

## Связь с текущим ядром

связь — единственная форма существования. существовать — значит быть связью. Смысл не существует отдельно от связи; связь и есть смысл в своей различённой форме.

```text
[] — минимальная завершённая форма одной связи
() — минимальная формальная форма смысла
{} — пустой пучок связей
```

## Несвязь и инверсия

Несвязь не существует в натуре. Смысл несвязи выражается связью.

```text
↛ — смысл несвязи
0 — абит связи, несущей смысл несвязи
```

Инверсия связи меняет направление натуральной связи. Инверсия смысла меняет смысл на обратный. Обратное направление связи не является отсутствием связи.

## Равенство

Равенство фиксирует совпадение форм связей. Равенство не является простой идентичностью определения. Формы связей являются видами самозамыканий. Рекурсивная процедура сравнения различает формы рекурсий. Равенство не требует бесконечного раскрытия рекурсивных связей.
