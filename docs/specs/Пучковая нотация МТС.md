# Пучковая нотация МТС

Статус: рабочее.

## Назначение

Пучковая нотация использует фигурные скобки `{...}` как контейнер пучка / асети связей.

```text
{...} — пучковая нотация; пучок / асеть связей
```

Пучок — различённый набор связей в данном контексте чтения. Это не одна связь и не форма одной связи. Пучок не тождественен элементу, который в него входит.

## Базовые формулы

В корневом ядре пучковая нотация задаётся через базовые формы `[]` и `[][]`:

```text
{} != []
{[]} != []
{[], []} = {[]}
{[], [][]} = {[][], []}
```

Смысл:

- `{}` — пустой пучок связей;
- `{[]}` — одноэлементный пучок из пустой формы одной связи;
- пучок не тождественен элементу;
- порядок элементов не важен;
- повтор элемента не создаёт новый элемент пучка.

## Экстенсиональное чтение

Рабочее чтение пучка экстенсионально:

```text
{[], []} = {[]}
{[], [][]} = {[][], []}
```

Порядок элементов не важен, а кратность не сохраняется. Мультпучковая версия с сохранением кратности остаётся открытым вопросом.

## Правое пучковое раскрытие

Форма:

```text
[]{[], [][]}
```

читается как пучок исходящих связей от формы `[]` к каждому элементу правого пучка:

```text
[]{[], [][]} = {[] ⟼ [], [] ⟼ [][]}
```

## Левое пучковое раскрытие

Форма:

```text
{[], [][]}[]
```

читается как пучок входящих связей в форму `[]` от каждого элемента левого пучка:

```text
{[], [][]}[] = {[] ⟼ [], [][] ⟼ []}
```

## Двустороннее пучковое раскрытие

Форма:

```text
{[], [][]}{[], [][]}
```

читается как пучок всех связей от каждого элемента левого пучка к каждому элементу правого пучка:

```text
{[], [][]}{[], [][]} = {[] ⟼ [], [] ⟼ [][], [][] ⟼ [], [][] ⟼ [][]}
```

## Роль в корневой системе

Пучковая нотация входит в корневой fixture как способ описания пучка / асети связей:

```text
{} != []
{[]} != []
{[], []} = {[]}
{[], [][]} = {[][], []}

[]{[], [][]} = {[] ⟼ [], [] ⟼ [][]}
{[], [][]}[] = {[] ⟼ [], [][] ⟼ []}
{[], [][]}{[], [][]} = {[] ⟼ [], [] ⟼ [][], [][] ⟼ [], [][] ⟼ [][]}
```

Эти строки фиксируют:

1. пустой пучок отличается от пустой формы одной связи;
2. одноэлементный пучок отличается от своего элемента;
3. пучок берётся экстенсиональным;
4. правое, левое и двустороннее раскрытие строят пучок явных связей.

## Что не входит в корневое ядро

Фиксация текущего PR: операционное удаление не входит в корневое ядро. Для него нужен отдельный механизм обобщения или переменных, потому что пока корневая система не вводит способ сказать "все исходящие связи" или "все входящие связи" без дополнительной нотации.

Также не входят в корень:

- переменные как первичные элементы;
- подстановка;
- мультпучки с сохранением кратности;
- восстановление пучковой записи из четверичного ачисла;
- связь пучковой нотации с остенсивной асетью за пределами формул fixture.
