# Пучковая нотация МТС

Статус: актуальное, нормативное.

## Назначение

`{...}` — пучковая нотация.

Пучок удерживает несколько форм связей как одну пучковую форму. Пучок не является формой одной связи.

```text
{} — пустой пучок связей
[] — минимальная завершённая форма одной связи
() — минимальная формальная форма смысла
```

## Различение слоёв

```text
(...) — круглая формальная нотация
[...] — квадратная ачисловая нотация
{...} — пучковая нотация
```

Пустой пучок связей отличается от минимальной завершённой формы одной связи. Пучковая форма не задаёт отсутствие натуральной связи.

## Несвязь

Несвязь не существует в натуре. Смысл несвязи выражается связью.

```text
↛ — смысл несвязи
0 — абит связи, несущей смысл несвязи
```

`{}` не является смыслом несвязи и не заменяет `[0]`.

## Вхождения

В `{[]}` фигурные скобки являются container-boundary пучковой формы, а `[]` внутри является one-link-form. В `([)` квадратная скобка является literal-abit в круглой формальной форме.
