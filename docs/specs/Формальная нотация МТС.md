# Формальная нотация Метатеории Связей (МТС)

## Версия 1.1

---

## 1. Введение

Настоящий документ представляет формальную нотацию Метатеории Связей (МТС) — единую, строгую и самосогласованную систему записи, охватывающую все аспекты теории: от базовых синтаксических конструкций до правил вывода и сериализации.

МТС основана на единственном примитивном понятии — **направленной связи** — и утверждает, что всё существование редуцируется к связям между элементами. Формальная нотация фиксирует это утверждение в виде точных определений, правил построения термов, аксиом и их следствий.

Документ объединяет и систематизирует материалы, представленные в репозитории, устраняя неоднозначности и обеспечивая единообразие записи.

## 2. Уровни языка

МТС различает два уровня языка:

### 2.1. Объектный язык

Объектный язык — формальные конструкции самой теории:

| Категория | Символы | Описание |
|-----------|---------|----------|
| Константы | `∞`, `𝟙` | Ассоциативный корень, единица смысла |
| Бинарный квантор | `⟼` | Направленная связь (конструктор существования) |
| Унарные кванторы | `♂` (префиксный), `♀` (постфиксный) | Начальность (самозамыкание начала), конечность (самозамыкание конца) |
| Унарный оператор | `-` (префиксный) | Инверсия направленности |
| Оператор степени | `^` (постфиксный) | Степень петли |
| Конструктор определения | `:` | Определение как запрос по форме |
| Отношения | `=`, `≠` | Равенство, неравенство |
| Группировка | `( )` | Переопределение порядка группировки |
| Множества связей | `{ }` | Шаблоны множественных связей |

### 2.2. Метаязык

Метаязык — правила работы с объектным языком:

| Символ | Описание |
|--------|----------|
| `⇒` | Мета-следование |
| `⇔` | Мета-эквивалентность |
| `C[ ]` | Контекст (метапеременная для выражения) |
| `a, b, c, r, s, t, v, x, y` | Метапеременные для связей |
| `n, m` | Метапеременные для натуральных чисел |

## 3. Синтаксис

### 3.1. Термы (связи)

Термы строятся индуктивно по следующим правилам:

1. **Константы**: `∞` и `𝟙` — термы.
2. **Метапеременные**: `a`, `b`, `c`, ... — термы (обозначают произвольные связи).
3. **Связь**: Если `a` и `b` — термы, то `(a ⟼ b)` — терм.
4. **Самозамыкание начала**: Если `a` — терм, то `(♂a)` — терм.
5. **Самозамыкание конца**: Если `a` — терм, то `(a♀)` — терм.
6. **Инверсия**: Если `a` — терм, то `(-a)` — терм.
7. **Степень**: Если `a` — терм и `n ≥ 1` — натуральное число, то `(a^n)` — терм.
8. **Множество**: Если `a₁, ..., aₖ` — термы, то `{a₁, ..., aₖ}` — терм.

### 3.2. Формулы

1. **Равенство**: Если `a` и `b` — термы, то `a = b` — формула.
2. **Неравенство**: Если `a` и `b` — термы, то `a ≠ b` — формула.
3. **Определение**: Если `s` — символ и `F` — терм, то `s : F` — формула.

### 3.3. Приоритеты и ассоциативность операций

Приоритеты перечислены от высшего к низшему:

| Приоритет | Операция | Тип | Ассоциативность |
|-----------|----------|-----|-----------------|
| 1 (высший) | `♂` | Префиксный унарный квантор | Правая |
| 1 | `♀` | Постфиксный унарный квантор | Левая |
| 1 | `-` | Префиксный унарный оператор | Правая |
| 1 | `^n` | Постфиксный оператор | — |
| 2 | `⟼` | Бинарный квантор | Левая |
| 3 | `=`, `≠` | Отношения | — |
| 4 (низший) | `:` | Определение | — |

### 3.4. Правила группировки

1. **Левоассоциативность `⟼`** (прямоассоциативность):
   ```
   a ⟼ b ⟼ c  =  (a ⟼ b) ⟼ c  ≠  a ⟼ (b ⟼ c)
   ```

2. **Сокращённая запись связи**:
   ```
   ab  =  a ⟼ b
   abc  =  (a ⟼ b) ⟼ c
   abcd  =  ((a ⟼ b) ⟼ c) ⟼ d
   ```

3. **Скобки переопределяют порядок**:
   ```
   a(bc)  =  a ⟼ (b ⟼ c)
   a(bcd)  =  a ⟼ ((b ⟼ c) ⟼ d)
   ab(cd)  =  (a ⟼ b) ⟼ (c ⟼ d)
   ```

4. **Правоассоциативность `♂`**:
   ```
   ♂♂v  =  ♂(♂v)
   ```

5. **Левоассоциативность `♀`**:
   ```
   r♀♀  =  (r♀)♀
   ```

6. **Комбинированная запись**:
   ```
   ♂a♀  =  (♂a)♀
   ```

## 4. Система аксиом

### А1. Аксиома определения (определение есть связь от знака к форме)

**Формально** (схема аксиом):
```
(s : F) ⟼ (s = F)
```
где `s` — вводимый символ (знак), `F` — терм (форма).

**Содержательно**: определение — это связь, в которой начало есть знак `s` (ссылка), а конец есть форма `F` (значение). Символ вводится как запрос по форме ко всем связям в асети, удовлетворяющим форме `F`. Из определения `(s : F)` следует структурная тождественность `s = F`. Начало и конец определения задают его смысл как направленное отношение от знака к форме (в силу аксиомы смысла А4). Паттерн формы и его резолюция возникают синхронно — нет цикла «имя → объект → имя».

**Свойства**:
- Ориентированность: `(s : F) ≠ (F : s)` — определяется знак формой, не наоборот
- Единственность: если `s : F` и `s : G`, то `F = G`
- Рекурсия разрешена, но только под конструктором `⟼` (guarded recursion)
- Синхронность: знак и форма возникают одновременно в едином акте различения

---

### А2. Аксиома конгруэнции (структурное равенство)

**Формально** (схемы аксиом):
```
((a ⟼ b) = (c ⟼ d))  ⟼  {a = c, b = d}
{a = c, b = d}  ⟼  ((a ⟼ b) = (c ⟼ d))

(♂a = ♂b)  ⟼  (a = b)
(a = b)  ⟼  (♂a = ♂b)

(a♀ = b♀)  ⟼  (a = b)
(a = b)  ⟼  (a♀ = b♀)

(-a = -b)  ⟼  (a = b)
(a = b)  ⟼  (-a = -b)
```

**Содержательно**: связи равны тогда и только тогда, когда равны их компоненты. Равенство конгруэнтно относительно всех конструкторов.

**Следствие** (единственность акорня):
```
(x = x ⟼ x) ⇒ (x = ∞)
```

---

### А3. Аксиома связи

**Формально**:
```
rv : (r ⟼ v)
```

**Содержательно**: связь — неделимая тройственность начала `r`, конца `v` и самой связи `rv`. Оператор `⟼` — бинарный, левоассоциативный конструктор существования. Формула `rv : r ⟼ v` — не правило сокращения записи, а онтологический постулат: `rv` обозначает связь как целостность, `r ⟼ v` — её направленную структуру.

**Ограничения**:
- Запрещена транзитивность: из `r ⟼ v` и `v ⟼ x` **не** следует `r ⟼ x`
- `⟼` существует только как оператор, не как отдельная связь

---

### А4. Аксиома смысла

**Формально**:
```
∞ : (∞ ⟼ ∞)
```

**Содержательно**: `∞` есть смысл. Смысл есть связь смыслов: `∞ : ∞ ⟼ ∞`. Это онтологический якорь системы — единственная полностью самозамкнутая связь, удовлетворяющая форме `x = x ⟼ x`.

**Свойства**:
- `∞ = ∞ ⟼ ∞` (смысл есть связь смыслов)
- Для любого `n ≥ 1`: `∞ⁿ = ∞`
- `∞` не является абитом и не входит в состав четверичных ачисел
- `∞` выражается через абиты: `[] = ∞`

---

### А5. Аксиома начальности (самозамыкание начала)

**Формально**:
```
♂x : (♂x ⟼ x)
```

**Содержательно**: `♂x` — связь, в которой начало (ссылка) совпадает с самой связью, а конец (значение) — внешняя связь `x`. Аксиома определяет понятие начала связи через форму безначальности: начало — это безначальная связь, замкнувшая своё начало на саму себя. Унарный, префиксный, правоассоциативный квантор.

**Свойства**:
- `♂x = ♂x ⟼ x` (выводимое тождество)
- `♂(♂x) = ♂(♂x ⟼ x)` (вложенное самозамыкание)
- `♂a = ♂b ⇔ a = b` (инъективность)
- `-(♂x) = x♀` (связь с инверсией)
- `♂x ≠ ∞` для любого `x` (частичное замыкание ≠ полному)
- `♂(ab) = b` (извлечение конца связи)

---

### А6. Аксиома конечности (самозамыкание конца)

**Формально**:
```
x♀ : (x ⟼ x♀)
```

**Содержательно**: `x♀` — связь, в которой конец (значение) совпадает с самой связью, а начало (ссылка) — внешняя связь `x`. Аксиома определяет понятие конца связи через форму бесконечности: конец — это бесконечная (без-конечная) связь, замкнувшая свой конец на саму себя. Унарный, постфиксный, левоассоциативный квантор.

**Свойства**:
- `r♀ = r ⟼ r♀` (выводимое тождество)
- `(x♀)♀ = (x ⟼ x♀)♀` (вложенное самозамыкание)
- `a♀ = b♀ ⇔ a = b` (инъективность)
- `-(x♀) = ♂x` (связь с инверсией)
- `x♀ ≠ ∞` для любого `x` (частичное замыкание ≠ полному)
- `(ab)♀ = a` (извлечение начала связи)

---

### А6.1. Семантика извлечения компонентов связи

**Переосмысление операторов ♂ и ♀:**

Операторы ♂ и ♀ можно рассматривать не только как конструкторы самозамыканий, но и как операторы извлечения компонентов связи:

**♂ как оператор извлечения конца (значения):**
```
♂(a ⟼ b) = b
```

**Онтологическое обоснование**:
- ♂ определяет безначальную связь (самозамкнутое начало означает отсутствие внешнего начала)
- Безначальная связь — это связь, у которой есть только конец
- Поэтому ♂ извлекает **конец** (значение) связи

**♀ как оператор извлечения начала (ссылки):**
```
(a ⟼ b)♀ = a
```

**Онтологическое обоснование**:
- ♀ определяет бесконечную связь (самозамкнутый конец означает отсутствие внешнего конца)
- Бесконечная связь — это связь, у которой есть только начало
- Поэтому ♀ извлекает **начало** (ссылку) связи

**Мнемоника позиционирования:**
```
♂ab = b    (♂ слева → извлекает правый компонент)
ab♀ = a    (♀ справа → извлекает левый компонент)
```

**Определение инверсии через извлечение:**
```
¬(ab) : ♂(ab) ⟼ (ab)♀
¬(ab) : b ⟼ a
```

### А7. Аксиома инверсии

**Формально**:
```
-(a ⟼ b) : (b ⟼ a)
-(♂x) : (x♀)
-(x♀) : (♂x)
-∞ : ∞
```

**Содержательно**: оператор инверсии `-` меняет местами начало и конец связи. Это не логическое отрицание, а переориентация направленности.

**Свойства**:
- `-` — унарный, префиксный, правоассоциативный оператор
- `--a = a` (инволютивность)
- `-(a ⟼ b) = b ⟼ a`
- `-∞ = ∞` (акорень инвариантен)
- `-aa = aa` (петля инвариантна)

---

### А8. Аксиома петли

**Формально**:
```
aa : (a ⟼ a)
```

**Содержательно**: связь `aa` — локальный акт самотождества, в котором одна и та же связь `a` одновременно исполняет роль ссылки и значения. Это **не** полное самозамыкание (которое уникально для `∞`).

**Свойства**:
- `aa = a ⟼ a` (основное тождество)
- `aa ≠ ∞` для `a ≠ ∞` (петля — не акорень)
- `-aa = aa` (инвариантность)
- `aa = bb ⇒ a = b` (конгруэнтность)

---

### А9. Аксиома прямоассоциативности

**Формально**:
```
a ⟼ b ⟼ c  =  (a ⟼ b) ⟼ c  ≠  a ⟼ (b ⟼ c)
```

**Содержательно**: последовательности связей группируются строго слева направо. Каждая новая связь присоединяется к результату предыдущего акта связывания.

**Общая формула**:
```
a₁a₂...aₙ  =  ((...((a₁ ⟼ a₂) ⟼ a₃) ...) ⟼ aₙ)
```

---

### А10. Аксиома единицы смысла (связь)

**Формально**:
```
𝟙 : (♂∞ ⟼ ∞♀)
```

**Содержательно**: `𝟙` — базовая единица направленности (связь), соединяющая начало смысла `♂∞` с концом смысла `∞♀`. Это направленная связь от начала к концу — связь или единица смысла.

**Свойства**:
- `𝟙 = ♂∞ ⟼ ∞♀` (по определению)
- `𝟙 ≠ ∞` (направленность ≠ самозамыкание)
- `true ≔ 𝟙`, `false ≔ -𝟙`

---

### А10.1. Нуль смысла (несвязь)

**Формально**:
```
-𝟙 : (∞♀ ⟼ ♂∞)
```

**Содержательно**: `-𝟙` — инверсия единицы смысла, определяющая несвязь (отсутствие смысла). Это направленная связь от конца к началу — несвязь или нуль смысла. Символ `↛` обозначает отсутствие связи и равен `-𝟙`.

**Свойства**:
- `-𝟙 = ∞♀ ⟼ ♂∞` (по определению через инверсию А7)
- `↛ = -𝟙` (отсутствие связи)
- `-𝟙 ≠ ∞` (несвязь ≠ самозамыкание)

---

### Уточнение: связь между `𝟙`/`-𝟙` и абитами `1`/`0`

Аксиомы единицы и нуля смысла (А10, А10.1) и аксиомы абитов (А11) задают **одни и те же формы связей**, но в **разных доменах**:

| Домен форм (формульная нотация) | Домен сериализации (абиты) | Форма связи |
|---------------------------------|----------------------------|-------------|
| `𝟙` — единица смысла (связь) | `1` — абит наличия связи | `♂∞ ⟼ ∞♀` (от начала к концу) |
| `-𝟙` — нуль смысла (несвязь) | `0` — абит отсутствия связи | `∞♀ ⟼ ♂∞` (от конца к началу) |

Таким образом:
- **`(⟼)` и `1`** — оба определяются формой `♂∞ ⟼ ∞♀`, но `𝟙` (⟼) — это формульная константа, а `1` — абит для сериализации
- **`(↛)` и `0`** — оба определяются формой `∞♀ ⟼ ♂∞`, но `-𝟙` (↛) — это формульная константа, а `0` — абит для сериализации

Совпадение форм не случайно: абиты `1` и `0` являются **сериализованными представлениями** фундаментальных понятий связи и несвязи.

---

### А11. Аксиома абитов

**Формально** (лексические определения):
```
[ : ♂∞
] : ∞♀
1 : (♂∞ ⟼ ∞♀)
0 : (∞♀ ⟼ ♂∞)
```

**Содержательно**: четыре абита определяют четыре элементарные формы связей вокруг акорня `∞`. Абиты служат для сериализации связей в компактные четверичные последовательности (ачисла).

**Соответствие абитов формульным константам**:
- `1 = 𝟙` — абит единицы смысла (связь, от начала к концу)
- `0 = -𝟙` — абит нуля смысла (несвязь, от конца к началу)
- `[ = ♂∞` — абит начала смысла
- `] = ∞♀` — абит конца смысла

**Ограничения**:
- Только `[`, `]`, `1`, `0` являются абитами
- `∞` не является абитом и не входит в состав ачисел
- Абиты существуют только в домене сериализации ачисел

---

### А12. Аксиома степени петли

**Формально**:
```
a¹ = a
a² = a ⟼ a  =  aa
aⁿ = aⁿ⁻¹ ⟼ a    (для n > 1)
```

**Содержательно**: оператор степени `^` формализует повторяющиеся последовательности связей с левоассоциативной группировкой.

**Свойства**:
- `a³ = (a ⟼ a) ⟼ a = aa ⟼ a`
- `∞ⁿ = ∞` для любого `n ≥ 1`
- `aⁿ = bⁿ ⇒ a = b` (при фиксированном `n`)
- `a^∞ = ♂a` (бесконечная степень)

## 5. Фундаментальные теоремы

### Т1. Теорема о слиянии рекурсий

**Утверждение**:
```
♂♀ = ∞
```

**Доказательство**:
1. По А5: `♂♀ = ♂♀ ⟼ ♀` (ссылка `♂♀` — сама связь, значение — `♀`)
2. По А6: `♂♀ = ♂ ⟼ ♂♀` (ссылка `♂`, значение `♂♀` — сама связь)
3. Из (1) и (2), поскольку `♂♀` — одна связь:
   - Из (1): конец `♂♀` есть `♀`
   - Из (2): начало `♂♀` есть `♂`
   - Из (1): `♀ = ♂♀` (конец совпадает с целым)
   - Из (2): `♂ = ♂♀` (начало совпадает с целым)
4. Подставляя в (1): `♂♀ = ♂♀ ⟼ ♂♀`
5. По А4 (единственность): `x = x ⟼ x ⇒ x = ∞`
6. Следовательно: `♂♀ = ∞` ∎

### Т2. Теорема о нетождественности ♂∞♀ и ∞

**Утверждение**:
```
♂∞♀ ≠ ∞
```

**Доказательство**:
1. `♂∞♀ = (♂∞)♀` (по правилам приоритетов)
2. По А6: `(♂∞)♀ = ♂∞ ⟼ (♂∞)♀`
3. Предположим `♂∞♀ = ∞`. Тогда: `♂∞ ⟼ ♂∞♀ = ∞ ⟼ ∞`
4. По А2: `♂∞ = ∞` и `♂∞♀ = ∞`
5. Но `♂∞ = ♂∞ ⟼ ∞` (по А5), а `∞ = ∞ ⟼ ∞` (по А4)
6. По А2: `♂∞ = ∞ ⇒ ♂∞ = ∞` и `∞ = ∞` (тривиально)
7. Но из `♂∞ = ♂∞ ⟼ ∞` и `∞ = ∞ ⟼ ∞`, по А2: `♂∞ = ∞` влечёт `♂∞ = ∞` **и** `∞ = ∞`
8. Это противоречит инъективности `♂` (А5): `♂∞ = ♂b ⇒ ∞ = b`, но `♂∞ = ∞` означает `♂∞ = ♂♀` (по Т1), что требует `∞ = ♀`, а `♀` не является замкнутым термом
9. Следовательно: `♂∞♀ ≠ ∞` ∎

### Т3. Взаимная выразимость ♂ и ♀

**Утверждения**:
```
♂x = -(x♀)
x♀ = -(♂x)
```

Прямое следствие А7.

### Т4. Расширенное самозамыкание ∞

**Утверждение**: для любого `n ≥ 1`:
```
∞ = ∞ⁿ
```

**Доказательство** (индукция по `n`):
- База: `∞¹ = ∞` (по А12)
- Шаг: `∞ⁿ = ∞` (индукционное предположение). Тогда `∞ⁿ⁺¹ = ∞ⁿ ⟼ ∞ = ∞ ⟼ ∞ = ∞` (по А4) ∎

## 6. Два ортогональных домена

МТС работает в двух полностью разделённых доменах. Смешение доменов запрещено.

### 6.1. Домен форм связей (формульная нотация)

**Назначение**: описание абстрактных паттернов связей и метатеоретических отношений.

**Алфавит**:

| Символ | Категория | Описание |
|--------|-----------|----------|
| `∞` | Константа | Полностью самозамкнутая связь (акорень) |
| `𝟙` | Константа | Единица смысла |
| `⟼` (или `→`) | Бинарный квантор | Направленная связь |
| `♂` | Унарный квантор | Начальность (самозамыкание начала) |
| `♀` | Унарный квантор | Конечность (самозамыкание конца) |
| `-` | Унарный оператор | Инверсия направленности |
| `^` | Оператор степени | Степень петли |
| `=` | Отношение | Равенство |
| `≠` | Отношение | Неравенство |
| `:` | Конструктор | Определение как запрос по форме |
| `( )` | Группировка | Переопределение порядка |
| `{ }` | Шаблон | Множественные связи |
| `↛` | Константа | Отсутствие связи (`-𝟙`) |

**Примеры формул**:
```
∞ = ∞ ⟼ ∞                        — полное самозамыкание
♂v = ♂v ⟼ v                      — развёртка самозамыкания начала
r♀ = r ⟼ r♀                      — развёртка самозамыкания конца
♂♀ = ∞                            — слияние рекурсий
♂∞♀ = (♂∞)♀                      — приоритет операций
-(a ⟼ b) = b ⟼ a                 — инверсия связи
aa = a ⟼ a                        — петля
```

### 6.2. Домен сериализации ачисел

**Назначение**: представление структур связей в виде компактных последовательностей для хранения и обработки.

#### 6.2.1. Четверичные ачисла (базовая форма)

**Алфавит**: ровно 4 символа (абита):

| Абит | Форма связи | Описание |
|------|-------------|----------|
| `[` | `♂∞ = ♂∞ ⟼ ∞` | Начало связи (ссылка) |
| `]` | `∞♀ = ∞ ⟼ ∞♀` | Конец связи (значение) |
| `1` | `♂∞ ⟼ ∞♀ = 𝟙` | Наличие связи (истина) |
| `0` | `∞♀ ⟼ ♂∞ = -𝟙` | Отсутствие связи (ложь) |

**Правила**:
- `∞` **не** является абитом и **не** входит в состав ачисел
- `∞` выражается через комбинацию абитов: `[] = ∞`
- Любое ачисло — конечная последовательность из символов `[`, `]`, `1`, `0`

**Примеры**:
```
[]           — представление акорня ∞
[1]          — базовая структура
[[10]]       — вложенная структура
[1][[0]][[] ] — многомерная структура
```

#### 6.2.2. Строковые ачисла (человекочитаемая форма)

Строковые ачисла расширяют четверичные, используя символы UTF-8 для человекочитаемости, при этом сохраняя те же базовые абиты `[`, `]`, `1`, `0` для структурной разметки.

**Примеры**:
```
"пользователь 1 активный"  →  пользователь1активный
"система [состояние] готова"  →  система[состояние]готова
```

#### 6.2.3. Полная сериализация

Полная, без потерь запись структур ачисел с использованием того же алфавита абитов `[`, `]`, `1`, `0`.

### 6.3. Границы доменов

| Свойство | Домен форм связей | Домен сериализации ачисел |
|----------|--------------------|---------------------------|
| Символы | `∞, 𝟙, ⟼, ♂, ♀, -, =, ≠, :` | `[, ], 1, 0` |
| Назначение | Анализ паттернов | Хранение и обработка данных |
| Уровень | Метатеоретический | Практический |

**Запреты**:
- Формулы не являются данными ачисел
- Операторы формул не используются в сериализации
- Абиты не используются как операторы в формулах (кроме группировки)

## 7. Классификация связей по формам

Все связи классифицируются по четырём фундаментальным формам самозамыкания:

| Форма | Символ | Определение | Арность | Пример |
|-------|--------|-------------|---------|--------|
| Полное самозамыкание | `∞` | `∞ = ∞ ⟼ ∞` | Нульарный | `∞` |
| Начальность (самозамкнутое начало) | `♂` | `♂x = ♂x ⟼ x` | Унарный (префикс) | `♂v`, `♂∞` |
| Конечность (самозамкнутый конец) | `♀` | `x♀ = x ⟼ x♀` | Унарный (постфикс) | `r♀`, `∞♀` |
| Без самозамыкания | `⟼` | `r ⟼ v` | Бинарный | `a ⟼ b`, `♂∞ ⟼ ∞♀` |

### 7.1. Соответствие форм и абитов

| Абит | Форма связи | Вид формы |
|------|-------------|-----------|
| `[` = `♂∞` | `♂∞ ⟼ ∞` | Начальность (самозамкнутое начало) |
| `]` = `∞♀` | `∞ ⟼ ∞♀` | Конечность (самозамкнутый конец) |
| `1` = `♂∞ ⟼ ∞♀` | `♂∞ ⟼ ∞♀` | Без самозамыкания |
| `[]` = `∞` | `∞ ⟼ ∞` | Полное самозамыкание |

## 8. Множественные связи и мультиссылки

### 8.1. Синтаксис множеств

```
r{a, b}  =  {r ⟼ a, r ⟼ b}       — мультиссылка (одна ссылка, много значений)
{x, y}a  =  {x ⟼ a, y ⟼ a}       — мультизначение (много ссылок, одно значение)
r{}      =  r ⟼ {}                  — связь с пустым шаблоном
{}v      =  {} ⟼ v                  — пустой шаблон как ссылка
```

### 8.2. Соотношения

```
{x ⟼ a, y ⟼ a}  =  {x, y} ⟼ a   =  {x, y}a
{x ⟼ a, x ⟼ b}  =  x ⟼ {a, b}   =  x{a, b}
```

## 10. ASCII-совместимая нотация

Для обеспечения кроссплатформенной совместимости определяется ASCII-отображение:

| Unicode | ASCII | Описание |
|---------|-------|----------|
| `∞` | `INF` | Ассоциативный корень |
| `♂` | `M` | Начальность (самозамыкание начала) |
| `♀` | `F` | Конечность (самозамыкание конца) |
| `⟼` (или `→`) | `->` | Направленная связь |
| `=` | `==` | Равенство |
| `≠` | `!=` | Неравенство |
| `↛` | `!->` | Отсутствие связи |
| `𝟙` | `1` | Единица смысла |

**Примеры ASCII-записи**:
```
INF == INF -> INF
Mv == Mv -> v
rF == r -> rF
MF == INF
M(INF)F != INF
```

## 12. Формальная грамматика (BNF)

```
<терм> ::= <константа>
          | <переменная>
          | "(" <терм> "⟼" <терм> ")"
          | "♂" <терм>
          | <терм> "♀"
          | "-" <терм>
          | <терм> "^" <натуральное>
          | "(" <терм> ")"
          | "{" <список_термов> "}"

<константа> ::= "∞" | "𝟙"

<переменная> ::= "a" | "b" | "c" | "r" | "v" | "x" | "y" | ...

<натуральное> ::= "1" | "2" | "3" | ... | "∞"

<список_термов> ::= <терм>
                   | <терм> "," <список_термов>

<формула> ::= <терм> "=" <терм>
            | <терм> "≠" <терм>
            | <символ> ":" <терм>

<ачисло> ::= <абит>*

<абит> ::= "[" | "]" | "1" | "0"
```

## 13. Примеры разбора формул

### Пример 1: `♂∞♀`
```
♂∞♀
= (♂∞)♀                           [♂ — правоассоциативный, ♀ — левоассоциативный]
= (♂∞) ⟼ (♂∞)♀                   [по А6: x♀ = x ⟼ x♀, где x = ♂∞]
= ♂∞ ⟼ ♂∞♀                       [сокращённая запись]
```

### Пример 2: `♂♂v`
```
♂♂v
= ♂(♂v)                           [♂ — правоассоциативный]
= ♂(♂v) ⟼ ♂v                     [по А5: ♂x = ♂x ⟼ x, где x = ♂v]
```

### Пример 3: `r♀♀`
```
r♀♀
= (r♀)♀                           [♀ — левоассоциативный]
= (r♀) ⟼ (r♀)♀                   [по А6: x♀ = x ⟼ x♀, где x = r♀]
```

### Пример 4: `abcd`
```
abcd
= ((a ⟼ b) ⟼ c) ⟼ d              [левоассоциативность ⟼]
```

### Пример 5: `a(bc)`
```
a(bc)
= a ⟼ (b ⟼ c)                    [скобки переопределяют порядок]
```
