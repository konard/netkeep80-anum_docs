# Формальная нотация МТС

Статус: актуальное, нормативное.

## Связь и смысл

связь — единственная форма существования. существовать — значит быть связью.

Смысл не существует отдельно от связи. Связь и есть смысл в своей различённой форме.

Формальная нотация МТС фиксирует способы различения связей и смысловых ролей связей. Она не вводит внешний источник смысла.

## Натуральная связь и смысловая роль

Натуральная связь существует между началом и концом. Смысловая роль возникает, когда связь читается как форма смысла.

```text
натуральная связь — существующая форма;
смысловая роль — чтение этой формы как смысла.
```

## Базовый словарь акорня

```text
∞ : [] = [] ⟼ []
[] = ∞
∞ = ∞ ⟼ ∞

() : ♀() ⟼ ()♂

([) : (♀∞)
(]) : (∞♂)

(⟼) : (♀∞ ⟼ ∞♂)
(↛) : (∞♂ ⟼ ♀∞)

[1] : (⟼)
[0] : (↛)

♀[] : ♀[] = ♀[] ⟼ []
[]♂ : []♂ = [] ⟼ []♂

(=) : {♀[] = ♀[], []♂ = []♂}
(!=) : ¬(=)
```

Акорень несёт смысл смысла.

## Начало и конец формы связи

Полюса формы связи записываются в актуальной ориентации: `♀F` — начало формы, `F♂` — конец формы.

```text
♀[] : ♀[] = ♀[] ⟼ []
[]♂ : []♂ = [] ⟼ []♂
```

`♀[]` — начало формы связи, `[]♂` — конец формы связи. Старая ориентация `[]♀` и `♂[]` больше не является активным корневым символом: её чтение запрещено.

## Пустая круглая форма смысла

Круглая нотация `(...)` является формальной нотацией смысла.

`()` — минимальная формальная форма смысла.

```text
() : ♀() ⟼ ()♂
```

Эта формула читается так: смысл есть связь начала смысла с концом смысла.

## Квадратная абитовая нотация

`[...]` — квадратная ачисловая нотация.

```text
[] — минимальная завершённая форма одной связи
[1] — квадратная форма абита связи
[0] — квадратная форма абита несвязи
```

```text
[1] : (⟼)
[0] : (↛)
```

0 — абит связи, несущей смысл несвязи. 0 не означает отсутствие связи в натуре.

## Разные скобочные нотации

```text
(...) — круглая формальная нотация
[...] — квадратная ачисловая нотация
{...} — пучковая нотация
```

```text
[] — минимальная завершённая форма одной связи
() — минимальная формальная форма смысла
{} — пустой пучок связей
```

Три пустые формы различимы и не сводятся одна к другой:

```text
[] != ()
() != {}
{} != []
```

`[]` не является пустой формальной формой смысла, `()` не является пустым пучком, `{}` не является формой одной связи.

## Семантика вхождений

Видимый знак не равен вхождению знака. В `([)` символ `[` является literal-abit внутри formal-form. В `[1]` символы `[` и `]` являются container-boundary квадратной формы.

Подробное описание находится в [Семантике вхождений МТС](Семантика%20вхождений%20МТС.md).

## Несвязь и инверсия

Несвязь не существует в натуре. Смысл несвязи выражается связью.

Инверсия связи меняет направление натуральной связи. Инверсия смысла меняет смысл на обратный. Обратное направление связи не является отсутствием связи, и абит 0 не является отсутствием связи в натуре.

```text
↛ — смысл несвязи
(↛) : (∞♂ ⟼ ♀∞)
```

## Равенство

```text
♀[] : ♀[] = ♀[] ⟼ []
[]♂ : []♂ = [] ⟼ []♂
(=) : {♀[] = ♀[], []♂ = []♂}
(!=) : ¬(=)
```

Равенство фиксирует совпадение форм связей: начало сравнивается с началом (`♀[] = ♀[]`), конец — с концом (`[]♂ = []♂`). Равенство не является простой идентичностью определения. Формы связей являются видами самозамыканий. Рекурсивная процедура сравнения различает формы рекурсий. Равенство не требует бесконечного раскрытия рекурсивных связей.

`(!=)` вводится как отрицание равенства `¬(=)` и используется в формулах различимости форм, например `{} != []`.
