# Повторяемый промпт для итеративного наведения порядка

Копируй и запускай этот промпт повторно до тех пор, пока все пункты плана не будут выполнены.

---

## Промпт

```
Ты работаешь с репозиторием anum_docs — документация по Метатеории связей (МТС).

Прочитай файл docs/plan.md и проверь текущий статус выполнения плана.

Для каждого невыполненного пункта плана:
1. Проверь, действительно ли пункт ещё не выполнен (проверь файловую структуру).
2. Если пункт не выполнен — выполни его.
3. Отметь пункт как выполненный в docs/plan.md.
4. Сделай коммит с понятным сообщением.

После проверки всех пунктов:
1. Убедись, что корень репозитория содержит только README.md, LICENSE, .gitignore и папки.
2. Убедись, что docs/theory/Метатеория связей.md — это актуальный чистовик.
3. Убедись, что активная документация содержит только текущие theory/specs/research-файлы из docs/plan.md.
4. Проверь, что README.md содержит актуальную структуру проекта.
5. Если находишь новые проблемы — добавь их в plan.md и исправь.

Особое внимание при работе с чистовиком (docs/theory/Метатеория связей.md):
- Терминология: "начало/конец" вместо "ссылка/значение"
- Терминология: "смысл" вместо "роль"
- Знак ':' для определений новых символов
- Знак '=' для равенства связей
- Знак '¬' для инверсии (не '-')
- ♂ — безначальная связь (префиксный, извлекает конец): ♂(ab) = b
- ♀ — бесконечная связь (постфиксный, извлекает начало): (ab)♀ = a
- Следовать шаблону из docs/theory/Шаблон аксиом МТС.md
- Два ортогональных домена: формы связей и сериализация

Если все пункты выполнены, напиши: "План полностью выполнен. Порядок наведён."
```

---

## Как пользоваться

1. Открой чат с AI-ассистентом в контексте репозитория anum_docs.
2. Вставь промпт из блока выше.
3. Дождись выполнения.
4. Если не все пункты выполнены — запусти промпт ещё раз.
5. Повторяй до получения сообщения «План полностью выполнен.»
